pixelfx — ресерч-стенд для Alien Cosmic ресерч · 09.11.2026

40 эффектов из библиотеки patch-gg/pixelfx (MIT, чистый canvas 2D — без картинок и шейдеров), в отборе под наши нужды: турели, кхариды, инфраструктура базы, экономика, атмосфера. Тап по кадру — повтор, кубик — новый seed. Переключатель ниже красит эффекты в язык «Рубежа 64» (бирюза Гелиоса / раскалённый коралл кхарид) поверх родных палитр.
Источник: patch-gg/pixelfx · MIT License (вендорен в stands/pixelfx-stand/core+fx, лицензия рядом). Часть рецептов адаптирована авторами библиотеки из открытых эффектов Sprite Fusion / Hugo Duprez (атрибуция в шапках файлов). Сравнение с оригинальной галереей: patch-gg.github.io/pixelfx.
