# БД на lovii — постоянное хранилище прогресса (пошагово)

Цель (владелец, 26.10.2026): одна БД на lovii, все сохранения со всех устройств
(Pages с телефона/браузеров, три машины) идут туда. Пин/ник те же: best / 0000.

## Что ставится на lovii (2 программы, обе бесплатны)

1. **Сейв-сервер игры** — уже написан: `server/save-server.mjs` (node:sqlite, ноль зависимостей).
2. **cloudflared** — туннель, который даёт https-адрес, доступный со всего интернета.

## Шаги на lovii

```bash
# 0) один раз: Node.js ≥ 22.5 (https://nodejs.org, LTS)

# 1) скопировать папку проекта (или git clone) на lovii, затем:
cd alien-cosmic
PORT=8790 node server/save-server.mjs
# увидишь: [save-server] :8790, db: …/saves.db — сервер жив

# 2) туннель (в новом окне терминала):
#    macOS:   brew install cloudflared
#    Windows: скачай cloudflared-windows-amd64.exe с github.com/cloudflare/cloudflared/releases
cloudflared tunnel --url http://localhost:8790
# в выводе появится строка:  https://слово-слово-слово.trycloudflare.com
# ЭТО АДРЕС ТВОЕЙ БД — скопируй его.
```

Проверка: открыть `https://…trycloudflare.com/health` → `{"ok":true,…}`

## Шаги в игре (любое устройство, 1 раз)

КЦ → «Профиль» → раскрой **«сервер БД (lovii/туннель)»** → вставь адрес
`https://…trycloudflare.com` → OK. Перезагрузить страницу.

После этого: «сервер: на связи · канал: внешний сервер (lovii)» — и все
сохранения идут в БД на lovii. Перезагрузки телефона/браузеров — база та же.

## Важно

- Туннель живёт, пока запущен `cloudflared` (окно терминала не закрывать; адрес
  при быстром туннеле меняется при перезапуске — тогда обновить адрес в профиле).
  Стабильный постоянный адрес — бесплатная регистрация на cloudflare и
  `cloudflared tunnel create lovii` (могу настроить, когда захочешь).
- Сейв-сервер на lovii держи запущенным тем же окном (`node server/save-server.mjs`).
- Mac-мост и гист остаются запасным каналом — не мешают.

## Миграция базы (координатор делает сам)

После того как lovii-адрес появится в профиле, координатор переносит базу best
из гиста в lovii-БД одним скриптом (values уже в гисте — читаются публично).
