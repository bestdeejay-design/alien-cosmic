**Alien Cosmic** — классическая стратегия в реальном времени, которая работает
целиком в браузере. Приведите колонистов-людей или рой кхарид к победе на
чужих планетах: стройте базы, добывайте кристаллы, исследуйте улучшения и
проходите кампанию из 15 миссий. Без установки и регистрации — открыл
страницу и играешь.

**🇬🇧 English version of this README: [README.md](README.md).**

## Чем игра отличается

- **Чужие планеты как персонаж.** Три биома (ржавый Актан-4, фиолетовые
  пустоши улья Брок-Тхаал, реголит Селенита-Б) — это не «скины», а сцены
  истории: колониальные поля добычи, священные колыбели кхарид, заброшенные
  лунные карьеры.
- **Конфронтация с обеих сторон.** У каждой силы своя правда: «Гелиос» видит
  в кристаллах топливо и прибыль, кхарид — колыбели выводка. Сюжет
  развивается в обе стороны (см. [ROADMAP.md](ROADMAP.md), фаза Ф5).
- **Ни одной «мёртвой» ситуации.** Рабочий погиб на стройке — стройка встала,
  но её можно достроить другим рабочим; выход из казармы заперт — юнит ждёт
  у ворот, а не застревает в корпусе; кристаллы распределяются без толпы.
  Всё, что игрок видит, он может разрешить осознанным действием.
- **Авто-режимы снимают рутину.** Рабочие сами возвращаются к добыче после
  стройки, бойцы отстреливаются на ходу без срыва приказа, наниты лечат на
  марше, двойной клик собирает всех таких же. Рутина — на игре, стратегия —
  на игроке.
- **Готовность к сетевой игре.** Архитектура с фиксированным шагом логики и
  приказами-командами проектируется так, чтобы впоследствии построить на ней
  реплеи, лобби и PvP (см. [ARCHITECTURE.md](ARCHITECTURE.md)).

## Управление

| Действие | Клавиши |
|---|---|
| Выделение / рамка | ЛКМ, ЛКМ-тянуть |
| Все такие же юниты на экране | двойной клик/тап по юниту |
| Приказ (идти/добывать/атака/ремонт) | ПКМ по земле/кристаллу/врагу/своему |
| **Атака-движение** | **A**, затем ЛКМ по точке (отмена — ПКМ/Esc) |
| Точка сбора здания | выделить здание → ПКМ; **на кристалле — новые рабочие сразу добывают** |
| Группы | Ctrl/Shift + 1…9 (назначить), 1…9 (выбрать) |
| Стройка | B (или Q/W/E/R/T/Y/U/I), ЛКМ — место |
| Стоп | S |
| Камера | стрелки, край экрана, СКМ-тянуть, Пробел — к базе |
| Пауза | P |

## Запуск

Нужен любой статический сервер (ES-модули не работают с `file://`):

```bash
python3 -m http.server 8080
# откройте http://localhost:8080/
```

Никаких зависимостей, сборки и сети — только браузер.
Или играйте прямо сейчас: **https://bestdeejay-design.github.io/alien-cosmic/**

## Структура репозитория

```
index.html        — разметка (меню, кампания, брифинг, HUD)
style.css         — стили интерфейса
js/
  config.js       — ВЕСЬ баланс: юниты, здания, улучшения, биомы, ИИ
  map.js          — генератор карт (3 биома, симметрия, проходимость)
  pathfinding.js  — A* по сетке, пути к прямоугольникам
  units.js        — юниты: приказы, движение, добыча, стройка, бой
  buildings.js    — здания: очереди, турели, гарнизоны, спавн
  ai.js           — ИИ противника (профили миссий)
  missions.js     — 15 миссий / 3 акта, прогресс
  raid.js         — локальный raid-loop (домашний корабль-КЦ, тиры 1–5, челнок)
  fog.js          — туман войны
  input.js        — управление и камера
  ui.js           — панель команд, тултипы, миникарта, меню
  audio.js        — синтез звука (Web Audio)
  game.js         — точка входа, игровой цикл, победа/поражение
scripts/
  check.mjs       — статический валидатор (синтаксис, импорты, html)
CAMPAIGN.md       — архитектура кампании и дуга сюжета
GAME_GUIDE.md     — полный справочник: сюжет, фракции, юниты, миссии (RU)
GAME_GUIDE.en.md  — полный справочник (EN)
LORE.md / LORE.en.md — лор мира (RU/EN)
RESEARCH_CLASSIC_RTS.md — ресерч классических RTS (референсы)
ROADMAP.md        — план развития (Ф2…Ф7)
ARCHITECTURE.md   — архитектура и путь к сетевой игре
```

## Технически

- **Чистый JavaScript**: ES-модули, Canvas 2D, Web Audio. Без фреймворков,
  сборщиков, рантайм-зависимостей и сетевых запросов — вся игра лежит
  статикой на GitHub Pages.
- **Фиксированный шаг симуляции** и приказы-команды — детерминированность
  заложена в архитектуру, реплеи и сетевая игра садятся сверху.
- **Баланс живёт в одном файле** (`js/config.js`) — тюнинг не трогает движок.
