# Навык: Финтех-проверки (`security-audit-fintech`)

Используй для платежей, кошельков, переводов, биллинга и любых сервисов с настоящими деньгами и PII.
Только тестовые данные и staging без отдельного разрешения.

## Приоритеты (детально — [../security-audit-core/support/checklists/fintech.md](../security-audit-core/support/checklists/fintech.md))

1. **Ledger и деньги:** двойная запись, double spend/race, идемпотентность, транзакционность, округления/валюты, лимиты, возвраты, сверка.
2. **Платежи/вебхуки:** подпись, replay, идемпотентность, сумма не с клиента, receipt на сервере, тестовые/боевые ключи разделены.
3. **Доступ:** IDOR на средства, tenant isolation, роли (саппорт без авто-доступа к средствам), MFA, сессии.
4. **KYC/AML/PII:** обход KYC, PII в логах, маскирование, экспорт с аудитом.
5. **API/ключи/операции:** API-ключи (хеш, scopes, отзыв), секреты в secret manager, rate limiting, audit trail, бэкапы без дублей.

## Правила

- Каждая находка про деньги — сценарий на тестовых счетах со сверкой ledger до/после.
- Регуляторные выводы — только как «требуется юридическая проверка»; агент даёт технические факты.
- P0 для финтеха: double spend, IDOR на средства, подделка вебхука, утечка секретов.
