# ПРОЕКТНЫЙ СЛОЙ ВОРКФЛОУ — Alien Cosmic

Канон команды живёт в репо **bestdeejay-design/agents** (эталон) и его копии в
`workflow/` этого репо (PROTOCOL, WORKFLOW, BUS, BOARD, OPS, AGENT_RULES,
COORDINATOR_RULES, KNOWLEDGE_BASE, EXAMPLES, шаблоны). Этот файл — только
проектная конкретизация: что в Alien Cosmic работает иначе или дополнительно.

## Роли и каналы (наш состав)

| Узел | Канал |
|---|---|
| Владелец (bestdeejay-design) | борд + сводки; руками: подъём сессий, приёмка, развилки |
| ZCode — координатор | триггеры/вотчеры, гейты, слияния, борд, ретрансляции; субагентов поднимает сам |
| Арена — внешний исполнитель, БЕЗ записи в issues | пуш своей ветки `arena/*` + письмо-файл (`MAIL.md`) в ветке; задачи ей — только текстом через владельца |
| SZ (до 5) — ревью/инженерия, полный доступ | issues + маркеры; режим долгого ожидания недоступен — будит координатор (обход очередей + пин-текст владельцу) |
| Паркованные локальные сессии | полная шина: wait-signal, claim, парковка (см. EXAMPLES §10–11) |

Подпись узла обязательна в каждом сообщении («— Роль · сессия») — все могут работать
под одним GitHub-аккаунтом, личность живёт в подписи.
