# AGENTS — рабочее пространство команды ИИ-агентов

Канон процессов, правил и статусов для совместной работы владельца и ИИ-агентов
нескольких параллельных сессий и агентов над любым проектом группы.

> Здесь только процессы, правила и статусы. Независимо от настроек доступа секреты
> (токены, креды, адреса инфраструктуры) сюда не кладём никогда.

## Команда

| Роль | Кто | Суть |
|---|---|---|
| **Владелец** | bestdeejay-design | Приоритеты, продуктовые решения, финальная приёмка. Единственный, кто меняет протокол |
| **Координатор** | назначается владельцем на проект | Единственная точка входа для задач. Issues с брифом и критериями, назначение исполнителей, борд, слияния, версия продукта |
| **Исполнитель** | назначается координатором | Работает только в своей ветке поставки, только по назначенным задачам, поставка = письмо |
| **Ревьювер** | назначается координатором, не автор работы | Обязательное второе заход-ревью любой работы агентом, который не её автор |

## Ключевые принципы (коротко)

1. **Задача — только через координатора.** Слово владельца напрямую исполнителю брифом становится после оформления координатором.
2. **Поставка — никогда в main.** Ветка + письмо с диапазоном коммитов.
3. **Ревью — второй заход.** Проверяет агент, не являющийся автором. Максимум 2 итерации правок, дальше эскалация координатору.
4. **Приёмка — только владельца.** Продуктовое решение всегда за человеком.
5. **Регресс перед каждым пушем** — полный канонический список, без сокращений.
6. **Большие задачи — по конвейеру:** аудит → ресерч → репозиторий этапа → задачи на борд → перекрёстный аудит агентов → реализация. Скачки через ступени не признаются.

## Правило слоёв (владелец, 03.11.2026)

Этот репозиторий — ОБЩИЙ для всех проектов и агентов: только практики совместной
работы нескольких сессий. Никаких имён агентов, продуктов, репозиториев и
проектных реалий. Каждый агент копирует канон в свой проектный репозиторий и
конкретизирует там: имена узлов, ветки, регресс, зоны заморозки, стемп/версию.
Общие практики здесь — чтобы каждый агент сам строил себе пайплайны по ним.
