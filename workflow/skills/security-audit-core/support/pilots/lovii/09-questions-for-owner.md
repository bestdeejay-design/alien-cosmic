# Вопросы владельцу <client> (осталось закрыть)

> ✅ **Ответ 1:** есть staging с моками банка и касс — `staging.example.com`, поэтому боевые платежи не проводим.
> ✅ **Ответ 2:** staging существует и доступен, тестируем на нём.
> Ниже — что ещё нужно. Отвечай коротко, можно «не знаю»: это тоже ответ.

## А. Блокирующие

1. **Тестовые аккаунты.** Можешь завести на staging: покупатель ×2 (для проверки доступа к чужим данным)
   и точку МСП? Есть ли админ/оператор?
2. **Окно.** Какие даты/часы удобны? Нужно 2–3 окна, чтобы не мешать, если на staging что-то демонстрируется.
3. **Кто останавливает.** Один контакт + канал (телефон/Telegram), по которому ты скажешь «стоп».
4. **b2b-staging** — есть и работает? Нужны доступы туда же (кабинет МСП).
5. **API-документация.** Есть OpenAPI/Postman/список эндпоинтов для `api-staging`? Можно получить?

## Б. Про моки и данные (важно для честности отчёта)

6. **Что именно замокано:** эквайринг <bank>, чеки 54-ФЗ, СБП-вывод, СМС/OTP — всё или часть?
   Есть ли флоу, который на staging всё-таки уходит в реальный банк?
7. **Данные на staging:** реальные люди/телефоны или тестовые? Есть ли реальные ПДн?
8. **Общие ресурсы staging ↔ прод:** одна БД, общий Redis/очередь, общий S3/хранилище фото,
   общие ключи? (Наблюдение: фото на staging грузятся с `b2b.example.com` — прод-домена.)
9. **Staging закрыт от поисковиков?** (robots/мета/базовая авторизация)
10. **Баллы на staging:** можно создать тестовый баланс, чтобы проверять начисление/трату/вывод?
11. **Логи и мониторинг:** куда пишутся, есть ли алерты на аномалии, дашь ли выписку по нашим тестам?

## В. Про процесс и результат

12. **Главный страх:** потеря денег, утечка данных точек, блокировка со стороны банка — что важнее?
13. **Кто исправляет** находки (ты / разработчик / подрядчик) и в какие сроки?
14. **Доступ к коду** для White Box — да/нет, и где код?
15. **Демо `demo.example.com`** — включаем в проверку или исключаем?
16. **NDA:** нужен отдельный документ или достаточно письменного согласия в переписке?
17. **Обезличенный кейс:** можно использовать пилот как пример для продажи услуги (без деталей, которые
    раскрывают твои слабые места)?
18. **Язык отчёта:** только русский или ещё английский (для инвестора/банка)?

## Г. Быстрые «да/нет»

- Пользователи реальные есть? да / нет
- На staging есть реальные ПДн? да / нет / не знаю
- Вывод баллов/денег точкам на staging работает? да / нет
- Есть отдельная админка/панель поддержки? да / нет
- Мультиязычность RU/EN влияет на логику цен/валют? да / нет
