# Чек-лист: Игровые проекты

> Дополнение к чек-листу режима. Каждый пункт: `проверено / не проверено (причина) / не применимо`.
> Детали рисков — [04-gaming.md](../04-gaming.md).

## Клиент vs сервер

- [ ] Урон/награды/дроп/баланс/инвентарь решает сервер.
- [ ] Валидация скорости/дальности/кулдаунов/последовательности на сервере.
- [ ] Подделка пакетов/replay: подпись, nonce, защита от повторов.
- [ ] Модификация клиента не даёт преимущества без детекта (в scope).

## Экономика и дюп

- [ ] Race на покупку/продажу/передачу; повторный запрос; обрыв сети; двойной клик.
- [ ] Отрицательные/нулевые/переполненные суммы; подмена цены/количества/валюты.
- [ ] Транзакционность покупки/продажи; идемпотентность оплаты/выдачи.
- [ ] Торговля/обмен: нельзя продать несуществующее, передать дважды, обойти комиссию.
- [ ] Фарм/мультиаккаунт/бот: лимиты, кап, анти-бот, сговор в турнирах/рейтингах.

## Донат и платежи

- [ ] Receipt проверяется на сервере (подпись); повторное/чужое использование.
- [ ] Вебхуки: подпись, идемпотентность, порядок, защита от подделок.
- [ ] Возвраты: отзыв валюты/предметов без дюпа.
- [ ] Промокоды: одноразовость, лимиты, запрещённые комбинации.

## RNG и честность

- [ ] RNG на сервере, энтропия достаточна, сид не уходит клиенту.
- [ ] Лутбокс: шансы = заявленным, выдача сервером, логи выдачи.
- [ ] Нельзя переролить повторным запросом/перезапуском.

## Аккаунты, UGC, античит

- [ ] Регистрация/вход/восстановление: enumeration, перебор, MFA для ценных аккаунтов.
- [ ] IDOR на инвентарь/профиль/историю/чаты; права модерации/админки.
- [ ] UGC/чат/моды: XSS, вредоносные загрузки, спам/флуд.
- [ ] Античит: что детектит, что — серверная валидация; ложные срабатывания и апелляция.
- [ ] Сохранения: целостность, версионирование, защита от подделки/отката; откат без дюпа.
