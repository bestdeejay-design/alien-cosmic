# Навык: Вёрстка и живая проверка UI (`ui-render-verification`)

Используй этот навык при аудите, разработке и ревью любых экранов, компонентов и стилей.

## Главный урок поля: наличие элемента в DOM не доказывает, что экран цел

Тест «кнопка нашлась селектором» пропускает наехавшие блоки, обрезанный `overflow: hidden`, нулевую высоту и сломанную мобилку. Любая правка UI проверяется по **живому рендеру и геометрии**.

## Обязательный чек-лист исполнителя и ревьювера

1. **Пять состояний каждого экрана/виджета:**
   - загрузка (`loading`), пустой список (`empty`), ошибка API/сети с понятным действием повтора (`error`), заполненные данные (включая длинные строки и много элементов), активная отправка (`disabled`/индикатор против двойного клика).
2. **Честная связка с API и окружением браузера:**
   - браузерный код никогда не стучится в `localhost`/`127.0.0.1` напрямую — только относительные пути/прокси или конфиг окружения;
   - все отображаемые поля реально приходят из ответа API, а ошибки `4xx`/`5xx` не роняют дерево компонентов белым экраном.
3. **Геометрическая и визуальная проверка в двух ширинах (`1440x900` и `375x812`):**
   - проверь `getBoundingClientRect()` ключевых блоков: `width > 0`, `height > 0`, нет горизонтального скролла страницы (`scrollWidth <= clientWidth`), нет перекрытия кликабельных элементов;
   - ноль `console.error`, `pageerror` и упавших запросов статики/шрифтов/API в сети.
