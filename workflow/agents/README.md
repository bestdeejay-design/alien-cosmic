# Роли саб-агентов и протокол коллегии (`agents/`)

Координатор (или ведущая сессия узла) **обязан** не тянуть аудит, ресёрч, кодинг и ревью в одном «замусоренном» окне контекста, а поднимать специализированных саб-агентов, явно выдавая каждому:
1. карточку роли из этой папки;
2. нужные модульные навыки из [`skills/`](../skills/README.md);
3. сжатый пакет входов (а для свежего исполнителя — ещё и предстартовый «пинок ревьювера»).

Генератор готового пакета запуска с автоподбором навыков и механической проверкой полноты входов: `scripts/spawn-pack` (`--auto`, `--from-issue`, `--preset fullstack-audit`). Нативные зеркала для автоподхвата в Claude Code / ZCode и Codex CLI поддерживаются в `.claude/{agents,skills}` и `.agents/skills` через `scripts/install-skills` (и раскатываются в любой проектный репо флагом `--target <путь> --with-harness`).

## Состав ролей

| Роль | Карточка | Запись в файлы | Обязательный контекст при старте | Главный выход |
|---|---|---|---|---|
| **Аудитор** | [auditor.md](./auditor.md) | Запрещена (`read-only`) | Бриф + радиус + паспорт модуля + `DEBT.md` | `AUDIT_PACK` + Линза 1 на коллегии (границы, инварианты, точки слома) |
| **Ресёрчер** | [researcher.md](./researcher.md) | Запрещена (`read-only`) | Бриф + `AUDIT_PACK` + принятые ADR | `SPEC_PACK` (варианты + сверка критериев) + Линза 2 на коллегии |
| **Ревьювер** | [reviewer.md](./reviewer.md) | Запрещена в режиме ревью | `AUDIT_PACK` + `SPEC_PACK` (до кода) и дифф + тесты (после кода) | До кода: `REVIEWER_KICK` (ловушки отказа); после кода: Линза 3 (`VERDICT` по `sha7`) |
| **Исполнитель** | [executor.md](./executor.md) | Разрешена (только в радиусе) | **Всегда свежий чистый саб** + `skills/` + `AUDIT_PACK` + `SPEC_PACK` + `REVIEWER_KICK` | Чистый минимальный дифф + прогон `scripts/preflight` + Линза 4 (карта хрупкости) |

## Адаптация по размеру задачи (`size:S / M / L`)

- **`size:S` (Fast-Track Дуэт, 1 волна):** без промежуточной паузы на `GATE OPEN`. Свежий [executor.md](./executor.md) со скиллом делает мини-аудит + код + `scripts/preflight`, затем свежий [reviewer.md](./reviewer.md) независимо прогоняет проверки и выдаёт вердикт на точный `sha7`. На пачке соседних `S`-задач роли между двумя сабами чередуются.
- **`size:M` (Полная коллегия 4 сабов + 2-я волна со сменой ролей):** [auditor.md](./auditor.md) + [researcher.md](./researcher.md) + предстартовый `REVIEWER_KICK` → свежий `Исполнитель-А` → параллельная коллегиальная проверка всеми 4 ролями → **Волна 2 со сменой ролей** (`Ревьювер-Б` становится `Исполнителем-Б` на фиксах и стресс-тестах, а `Исполнитель-А` становится `Ревьювером-А` и проверяет дифф Волны 2).
- **`size:L` (Полная коллегия + ADR + обязательные 2 волны со сменой ролей):** как `M`, плюс `ADR` и обязательная перекрёстная ротация `Исполнитель ↔ Ревьювер` как внутри задачи, так и между парными подзадачами этапа.

Полный пошаговый регламент двух волн и запрета само-ревью — в [collegium.md](./collegium.md).
