# DEBT — реестр технического долга (шаблон общего слоя)

> **Как этим пользоваться.** В проектном репозитории этот файл — живой реестр проекта:
> одна строка = один пункт долга. В этом общем репозитории ниже — только формат
> и правила; живые записи сюда пишут лишь о долге самого общего воркфлоу.
> Не чини долг «заодно» со своей задачей: каждый фикс долга — отдельный issue
> `type:debt` с полным циклом ARCA своего размера (см. docs/AGENT_RULES.md §7).

## Правила ведения

1. **Добавляет** любой агент, только в своей ветке поставки, одной строкой:
   следующий свободный ID вида `D-<NNN>`, модуль/зона, суть, где найдено (issue),
   риск `low` / `medium` / `high`.
2. **Статусы:** `open` → `in-progress (#N)` → `resolved (#N)`. Закрытую запись не удаляют:
   история долга — часть истории модуля. В паспорте модуля лежат только ссылки на ID.
3. **Конфликт файла при слиянии** разрешает координатор: сохраняет обе записи,
   перенумеровывает младшую. Исполнитель конфликт реестра сам не разрешает.
4. **Эскалации координатора:** запись `risk:high` — issue на устранение создаётся сразу;
   3 и более открытых записей на одну зону — issue на рефакторинг зоны.
5. **Осознанный новый долг** из фазы CONCLUSION («Новый долг: …») попадает сюда
   в той же поставке, а не «потом когда-нибудь».
