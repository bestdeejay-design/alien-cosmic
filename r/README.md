# r/ — ПОЛИГОН РЕЙДОВ (отдельно от лендинга)

Изолированная копия движка с рейдовым циклом (R0-a Арены) для опытов по механике
рейда БЕЗ изменений основной игры.

Канон владельца (25.10.2026):
- S1 (v1) в корне — НЕ модифицируем; лендинг не ссылается на этот полигон.
- При возврате рейдов в игру: UI не менять, новых кнопок не добавлять,
  механика — только через строения и юниты, сначала сохранение прогресса.
- Здесь правила канона можно нарушать: это песочница для поиска решений,
  которые потом переносятся в игру в рамках канона.

## Правила экономики (канон владельца, в коде)

1. **R1** — ни одно здание не грейдится выше уровня КЦ (кнопка видна, но закрыта и объясняет).
2. **R2a** — КЦ→L требует **L зданий уровня (L−1)+** (КЦ→3 = 3 здания II ур., КЦ→4 = 4 здания III ур.; КЦ считается).
   **R2b** — с КЦ→11 в этом наборе нужны **развитые** здания: казарма/завод/лаборатория/Дом
   (2 → 6 по мере роста уровня). Решение владельца «к 20 идти труднее».
3. **R3** — ранг юнита (лаборатория) не выше уровня КЦ.
4. **R4** — рейд открывает Дом Г2+, тир вылазки = уровень КЦ.

## Экономика в цифрах

- Домашняя добыча: **72 эрга/мин на рабочего**; домашнее месторождение конечно (~15 000 на старт).
- Рейд: тир 1 — 900 эрга/вылет, тир 20 — 131 573; доход 430 → 11 800 эрга/мин.
- База-20: **5 915 178 эрга** по рекомендуемому набору; «широкий» минимум — 3 127 160,
  но с КЦ→11 без развитых зданий он не проходит.
- Полные таблицы, порядок грейдов и открытые вопросы: **`design/ECONOMY_20.md`**.

PORT=8805 node server/static.mjs           # вся игра + прокси /api → :8790
#   http://localhost:8805/r/               — полигон рейдов

Быстрый прогон контента: `?econ=0.1` — все цены ÷10, `?econ=0.02` — ÷50 (для проверки 20 уровней за вечер).

## Первые 15 минут в рейдах (как играть)

1. **Обзор.** Старт: корабль-КЦ, 2 рабочих, 2 рейнджера, 200 эрга на счету.
   Слева ресурсы и цель, внизу панель команд, справа миникарта.
2. **Добыча.** Стартовые рабочие уже на жиле. Клик по рабочему → ПКМ по кристаллу
   (на телефоне: тап по рабочему, потом тап по жиле). Каждый рейс — 8 эрга,
   цикл ~7 секунд, то есть ~72 эрга/мин на рабочего.
3. **КЦ-II (240).** Тап по КЦ → кнопка «Грейд II» → ждём 30 с.
   *Зачем:* без КЦ-II ничего не грейдится (правило «не выше КЦ») и не открывается тир 2.
4. **Дом (100) + Дом-II (1 200).** Ставим Дом у КЦ (кнопка «Строить» у рабочего),
   затем грейдим до II. Появляется команда **«Вылазка» в панели самого Дома**.
5. **Первый вылет.** Выделяем Дом → «Вылазка» → выбираем тир 2 → состав (2 рабочих
   обязательно: они собирают эрг) → «Отправить челнок». В секторе: рабочие сами идут
   к жилам и сдают эрг в Дом-шаттл (трюм 3 000).
6. **Домой.** Выделяем Дом-шаттл → «Эвакуация» (или клик по кольцу посадки). Кто не
   заехал в кольцо за 2 секунды — потерян навсегда.
7. **Дальше:** КЦ-III требует 3 здания II уровня — стройте турели и бункер (они дешевле),
   с КЦ-XI понадобятся **развитые** здания (казарма/завод/лаба/Дом), иначе грейд КЦ закрыт.

Подсказки в интерфейсе: у кнопки грейда в правом верхнем углу — целевой уровень,
в тултипе — цена, время, эффект и причина блокировки; в консоли вылазки у каждого тира
написано, сколько эрга на карте и сколько берёт рабочий за рейс.

## Капсулы снабжения и админка (Э6)

Команды КЦ (новых кнопок в топбаре нет — канон владельца):

* **«Капсулы»** (`KeyC`) — список капсул: готова / закрыта с причиной / забрана.
  При заходе карточки появляются сами, если есть что забрать.
* **«Админ»** (`KeyO`, PIN по умолчанию `1234`) — экономика (масштаб цен),
  конструктор капсул (условия, награды, веса), топ игроков и подарки, диагностика.

Модель данных, правила антиабуза, идеи «хайпа» и ресёрч механик —
[`design/ADMIN_AND_CHESTS.md`](../design/ADMIN_AND_CHESTS.md).

## Командир КЦ и оборона базы (Э7)

* КЦ → **«Командир»** (`KeyK`): звание, опыт, бонусы, служба, журнал.
* Раз в 4–5 минут на базу приходит **входящий рейд** (предупреждение за 25 с,
  сирена, высадка у края карты). Командир с включённой автозащитой сам поднимает
  бойцов; свои получают бонус урона, рядом с КЦ работает ремонт.
* **«Учебная тревога»** в карточке — малая волна сразу, без награды: проверить
  оборону, не ожидая таймера.
* Над КЦ висит **вымпел** с ромбами звания (1–4, у генерала — звезда).
* Опыт: возврат с вылазки, отражённый рейд, уничтоженные враги. Путь 1→20 —
  8 740 XP. Опыт нельзя купить, капсулы его не дают.

Подробности — [`design/COMMANDER.md`](../design/COMMANDER.md).
Аудит и чек-лист «как поиграть» — [`design/QA_AND_PLAY.md`](../design/QA_AND_PLAY.md).
