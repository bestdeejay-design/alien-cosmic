# r/ — ПОЛИГОН РЕЙДОВ (отдельно от лендинга)

Изолированная копия движка с рейдовым циклом (R0-a Арены) для опытов по механике
рейда БЕЗ изменений основной игры.

Канон владельца (25.10.2026):
- S1 (v1) в корне — НЕ модифицируем; лендинг не ссылается на этот полигон.
- При возврате рейдов в игру: UI не менять, новых кнопок не добавлять,
  механика — только через строения и юниты, сначала сохранение прогресса.
- Здесь правила канона можно нарушать: это песочница для поиска решений,
  которые потом переносятся в игру в рамках канона.

## Что здесь есть (обновлено 25.10.2026, пакет Э1+Э2)

| Файл | Что делает |

| `raid-boot.js` | автозапуск рейд-хоума, эвакуация кликом по кольцу, сейв базы через общий клиент |

## Правила экономики (канон владельца, в коде)

1. **R1** — ни одно здание не грейдится выше уровня КЦ (кнопка видна, но закрыта и объясняет).
2. **R2a** — КЦ→L требует **L зданий уровня (L−1)+** (КЦ→3 = 3 здания II ур., КЦ→4 = 4 здания III ур.; КЦ считается).
   **R2b** — с КЦ→11 в этом наборе нужны **развитые** здания: казарма/завод/лаборатория/Дом
   (2 → 6 по мере роста уровня). Решение владельца «к 20 идти труднее».
3. **R3** — ранг юнита (лаборатория) не выше уровня КЦ.
4. **R4** — рейд открывает Дом Г2+, тир вылазки = уровень КЦ.

## Экономика в цифрах

- Домашняя добыча: **72 эрга/мин на рабочего**; домашнее месторождение конечно (~15 000 на старт).
- Рейд: тир 1 — 900 эрга/вылет, тир 20 — 131 573; доход 430 → 11 800 эрга/мин.
- База-20: **5 915 178 эрга** по рекомендуемому набору; «широкий» минимум — 3 127 160,
  но с КЦ→11 без развитых зданий он не проходит.
- Полные таблицы, порядок грейдов и открытые вопросы: **`design/ECONOMY_20.md`**.

## Запуск стенда

```bash
node server/save-server.mjs &        # БД сохранений (:8790)
PORT=8805 node server/static.mjs     # игра (:8805) + прокси /api → :8790
# http://localhost:8805/r/
```

Быстрый прогон контента: `?econ=0.1` — все цены ÷10, `?econ=0.02` — ÷50 (для проверки 20 уровней за вечер).
