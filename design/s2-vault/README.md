## Что здесь лежит

- `assets/s2/` — спрайты юнитов и зданий обеих фракций (вырезаны 1:1 из концепта, PNG).
- `assets/planets/` — планеты Актан-4, Брок-Тхаал, Селенит-Б (SVG).
- `concepts/` — концепт-арты (юниты, здания Гелиос/кхарид, постер Актан-4).
- `screenshots/` — рендеры из движка 960px (s2-final-* — финальные с новой отрисовкой).
- `docs/` — VISION.md, UNITS_VISUALS.md, SEASON2_PROMO.md, MEDIA_KIT.md (описание подхода).
- `promo/` — presskit.md, social-pack.md.

Всё содержимое — только ассеты и документы, без кода. Если Сезон 2 возродится (решение
владельца через координатора), ассеты переиспользуются напрямую; кодовая база S2 пишется
с нуля в `s2/` по канону AGENTS.md §5 (движок S1 — донор, правки запрещены).
