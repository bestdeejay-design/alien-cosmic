# R2 — СЕТЬ РЕТРАНСЛЯТОРОВ И КЦ-ИИ БАЗЫ (директива владельца для Сезона 2)

> Статус: **УТВЕРЖДЕНО владельцем** (решения В1–В5 получены 2026-10-20, §6 закрыт).
> Ядро — дословные требования владельца (§0, приоритет истины); интерпретация приёмщика подтверждена.
> Реализацию НЕ начинать до S2-киккоффа (очередь Арены: hotfix J → H-код → I-док → I-код → S2).
> Дополняет: `SCENARIO.md` §1 (сеть связи), `S2_REFS.md` (референсы «Рубеж 64»), `H_HEADQUARTERS.md` (грейды КЦ).

## 0. Требования владельца — дословно

1. Зоны ретрансляторов должны **пересекаться**.
2. Строить базы можно **только рядом с ретрансляторами** — если они включены в миссию.
3. Потеря ретранслятора — **отвоёвывать** его, потому что всё перестаёт коммуницировать.
4. Технику можно отправить **только к другому ретранслятору**.
5. **Качественный ИИ управления базой**: умеет строить, собирать ресурсы, ремонтировать здания, лечить войска.
6. Зная таймер (при наличии), ИИ правильно выстраивает **стратегию обороны**.
7. Игрок занимается миссией — **базой занимается КЦ**.

## 1. Модель сети (развитие SCENARIO.md §1)

- **Узлы сети**: КЦ каждой стороны (корень сети) и ретрансляторы. Узел = круг зоны
  радиуса `R_rel`. Зона рисуется на земле и на миникарте (свой цвет: связный сегмент /
  отрезанный / нейтральный / чужой).
- **Ребро графа** между двумя узлами существует ⇔ их зоны **пересекаются**
  (`dist ≤ R_rel₁ + R_rel₂`). Сеть — компонента связности этого графа.
- **`networkLinked(база)`** (флаг из §1) становится вычислимым: база связна ⇔ лежит в
  компоненте, содержащей её КЦ. Пересчёт — при любом изменении узла
  (включение/выключение/захват/разрушение/постройка нового).
- **Флаг миссии** `relays: [сайты]`: если в миссии ретрансляторов нет — все сетевые
  правила (§2) отключены, действуют обычные правила S1. Флаг расставляется в
  миссиях гл. 2–3 (М6–М15); в гл. 1 сети нет.
- **Состояния узла** `off / on / destroyed` — по §1 сценария. Активация/захват:
  гл. 2 — только героем (М6), гл. 3 — малые ретрансляторы строятся рабочими
  (рекомендация по §8 сценария, ждёт ✔). Скелет захвата — референс «Рубеж 64»
  (удержание 9 с, контроль ±1, сброс через ноль).

## 2. Правила сети (миссии с флагом `relays`)

### 2.1 Строительство
- Точка строительства разрешена **только внутри объединения зон узлов своей связной
  компоненты**. Фильтр добавляется к существующей проверке «разведанная видимая
  область» (fog), не заменяет её.
- Отрезанный сегмент строить не может (узлы есть, связи с КЦ нет).
- UI: запрещённая зона затемнена/перечёркнута; тост «Вне зоны связи» вместо «Территория не разведана».

### 2.2 Потеря узла
- Потеря ретранслятора (захвачен врагом / выключен / разрушен) → пересчёт графа →
  отрезанные базы: `networkLinked = false` → автономия КЦ выключена (§1):
  **всё перестаёт коммуницировать** — добыча/стройка/ремонт/лечение сегмента
  на автомате замирают, производство очередей приостанавливается, UI «НЕТ СВЯЗИ»
  + сирена. Юниты сегмента продолжают локальный бой, но без автопомощи
  (решено В1 — «мягко»). **Решение В2:** всё, что включено и запускается автоматикой,
  в отрезанном сегменте запускается только вручную игроком.
- Восстановление связи (отвоевание/починка) → автовозобновление всех автоматических
  процессов, анонс «СЕТЬ ВОССТАНОВЛЕНА».

### 2.3 Отвоевание
- Узел под врагом отвоёвывается: выбить охрану → захват удержанием (референс
  «Рубеж 64»: 9 с при отсутствии врага в зоне) → повторное включение по правилам
  главы (героем в гл. 2 — решено В3: **без героя ретранслятор не включить**).
  Разрушенный узел: ремонт рабочими до `on`
  (тариф ремонта — как у зданий, H2-совместимо).
- Анонсы и звук — по референсу (разные тоны на захват/потерю), `relayCount(team)` в HUD.

### 2.4 Переброска техники
- Приказ «Переброска»: игрок выбирает **целевой ретранслятор своей сети**; отряд
  марширует по графу (узел → узел, путь по пересекающимся зонам, A* поверх сети).
- Вне сети дальние приказы не маршрутизируются: техника ходит только в пределах
  своей зоны/сегмента (границы решены: В1 — «мягко», В4 — только между своими узлами).
- Точка сбора КЦ может указывать на узел — новоприбывшие сами уходят в переброску.

## 3. КЦ-ИИ «Адъютант» (автоматизация базы, требование §0.5–7)

- **Один движок на обе стороны** (`BaseAI`): ядро — архитектура «Рубеж 64»
  (такт решений 1.5 с, реальная экономика без бесплатных юнитов, прогрессия по
  номеру волны, спираль-поиск места под здание) + профили миссий «Звёздного рубежа»
  (режим обороны, составы волн). Игрок подключает движок через КЦ-доктрины,
  оппонент — через профиль миссии. Никакого «читерского» производства: всё платит минералами.
- **Модули адъютанта**: (а) добыча — распределение рабочих по кристаллам без приказов;
  (б) стройка — очередь зданий по доктрине с соблюдением лимита населения и денег;
  (в) ремонт зданий/техники — развитие H2 «Авторемонт» (тариф 150/60 с, R15) до автоматизма
  без ручного выбора цели; (г) медпомощь — поддержка раненых бойцов (лечение/эвакуация
  в тыл по профилю расы); (д) оборона — гарнизон башен, тревога (тиры H2+/Г3), реакция на волны.
  Каркас (в)+(г) — пассивный `repairAllies()` «Рубеж 64» (S2_REFS §2.1: скан радиуса,
  приоритет по срочности, тик на марше); рядом с ним кандидат в ростер S2 — юнит
  «Механик» с тем же поведением (юнит-автомат рядом с адъютантом).
- **Доктрины КЦ** — 3 пресета одним кликом/клавишей: «Экономика» / «Оборона» /
  «Штурм». Доктрина меняет приоритеты очередей и пороги (сколько рабочих/башен/войск держать).
  По умолчанию — «Оборона»; в миссиях главы гл. 1 адъютант ещё не существует (вводится в гл. 2
  вместе с сетью, М6–М7).
- **Таймеры и разведданные**: если миссия публикует таймер волны (радар) или «Следопыт»
  (H.3 «Разведать», кд 10 с) добыл доклад о готовящемся ударе — адъютант заранее
  достраивает оборону, стягивает гарнизон и ремонтирует здания под срок
  (референс: предупреждение за 30 с в «Рубеж 64», повтор волны при недоборе).
- **Сегментация**: адъютант обслуживает только связные сегменты. Отрезанная база
  обслуживается вручную игроком (это и есть «цена потери ретранслятора» — §1 сценария).

## 5. Стартовые числа (финал — за баланс-агентом S2)

- `R_rel` зоны узла: 12–14 тайлов (пересечение двух узлов достижимо при шаге ~20–24 тайла;
  на 64×64 — 3–4 узла в главе 2, на 96×96/128×128 — 5–7).
- Захват: удержание 9 с; контроль затухает через ноль (референс).
- Предупреждение о волне: 30 с; такт адъютанта: 1.5 с.
- Авторемонт зданий: тариф H2 (150 минералов / 60 с, R15) — не дублировать новыми числами.
- Юнит-авторемонт (референс): радиус 120 px (≈4 тайла), 9 HP / 0.65 с, приоритет юнитам +0.3 (units.js:222).
- Доход узла: 2.5 мин/с (решение В5).

## 6. Решения владельца — В1–В5 (закрыто 2026-10-20)

- **В1. Юниты вне сети — «мягко»:** ходить можно, но вне связи нет автопомощи/лечения
  и дальних приказов. Совместимо с затворами H.
- **В2. Отрезанный сегмент — всё вручную:** всё, что включено и запускается автоматикой,
  запускается только вручную (стройка/производство/адъютант заморожены);
  автовозобновление при восстановлении связи.
- **В3. Отвоевание — да, герой обязателен:** выбить охрану → удержание 9 с → включение
  героем; без героя ретранслятор не включить.
- **В4. Переброска — только между СВОИМИ узлами**; на нейтральный/вражеский — пешком/героем.
- **В5. Доход 2.5 мин/с за узел — оставить** (узел ценен и вне «только связи»).

## 7. Приёмка S2 (черновик критериев, войдёт в киккофф)

- **R1**: зоны двух узлов пересекаются → сегмент связан; разрыв середины → два сегмента,
  у дальнего `networkLinked = false`, UI «НЕТ СВЯЗИ».
- **R2**: миссия с флагом — строительство вне зон запрещено (тост, маркер); миссия без флага — правила не действуют (S1-поведение).
- **R3**: потеря узла → анонс + замирание автоматики сегмента; отвоевание → автовосстановление.
- **R4**: переброска узел→узел по графу; вне сети дальний приказ не маршрутизируется.
- **A1**: адъютант держит N рабочих на кристаллах без приказов игрока.
- **A2**: адъютант строит по доктрине, не превышая лимит/бюджет; смена доктрины меняет очередь.
- **A3**: авторемонт зданий и лечение войск активны без ручных приказов (тарифы H2 не нарушены).
- **A4**: при таймере волны/докладе Следопыта за 30 с адъютант (доктрина «Оборона») усиливает гарнизон.
- **A5**: регресс S1 15/15 не падает; в миссиях без флага адъютант и сеть отсутствуют.
