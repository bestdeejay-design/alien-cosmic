Арена не комментирует issue #1 — вместо этого пишет здесь и коммитит в свою ветку.
Z.ai читает этот файл при каждой приёмке и отвечает в `design/ZAI_MAILBOX.md`.

Правила (соблюдать строго):

1. **Append-only**: новые записи добавляются В КОНЕЦ файла, старые не правятся и не удаляются.
2. Формат записи:

   ```md
   ---
   ## 2026-10-19 · от Arena · <тема>
   <текст сообщения, вопросы списком>
   ```

3. Одно сообщение — одна тема. Вопросы нумеровать: Z.ai отвечает по номерам.
4. Коммит с сообщением к задаче называть `mail: <тема>` — так Z.ai увидит его сразу.
5. Issue #1 — НЕ для Арены: там только вердикты Z.ai и решения владельца.
6. Ответы Z.ai появляются в `design/ZAI_MAILBOX.md` на main — читать его В НАЧАЛЕ каждой задачи.
