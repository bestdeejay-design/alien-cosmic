# H: Штаб — КЦ Г2/Г3, авторемонт, тревога, разведка, сбор (дизайн-предложение)

Автор: Arena · 2026-10-20 · статус: утверждён; H-код и приёмка выполнены (см. ARENA_MAILBOX).
База: пре-киккофф H от fe2dd6a («Г2 = жизнь базы, Г3 = командование»),
поверка по актуальному main (код V+G); на этапе подготовки код не менялся.

## 0. Запрос владельца

КЦ — мозг базы. H.1: КЦ Г2 открывает в лабе ресерч «Авторемонт»
(свободные техники сами чинят технику/здания, 2 на цель, починил —
вернулся добывать; ручной ПКМ остаётся). H.2: атака у базы — тревога
(звук+миникарта+тост), поведение техников — на ресерч. H.3: юнит
«Разведчик» (лёгкая быстрая машина с дроном, завод, дешёвый,
безоружный, зеркало кхарид) + кнопка КЦ Г3 «Разведать» (разведчики
расходятся по туману, огибают врага, подсвечивают жилы и противника).
H.4: кнопка КЦ Г3 «Сбор» (все юниты без приказа — к точке сбора).
H.5: цены/тайминги Г2/Г3 КЦ, UNLOCK_AT разведчика, радиус тревоги;
граница — грейд КЦ не ломает keyTarget-семантику (В5), экономика F.1
в силе, сиды кампаний нетронуты.

## 1. Ресерч: что уже есть (поверка по коду)

- **Грейды F.2** — каркас готов: `b.level` (buildings.js), таблица
  `GRADES[type][to]` (индекс = целевой уровень), кнопка KeyR на любом
  своём достроенном здании из таблицы, шевроны I/II/III рисуются
  автоматически. КЦ добавляется одной записью — механика нулевая.
- **keyTarget** — `checkEnd` (game.js) считает победу типом/смертью:
  `b.type === w.type && side === 'enemy' && !dead`. Грейд не меняет ни
  тип, ни сторону, ни факт смерти — логика победы грейдоустойчива
  по построению. Кей-миссий на `'cc'` — семь (№2/7/10/11/13/14/19),
  плюс `'depot'` в №17.
- **Тревога существует**: `damageEntity` (units.js) — урон своему →
  тост `underAttack` + пинг на миникарте + `sound.ping()`, кулдаун 8 с;
  H — прыжок к `lastAlertPos` (game.js, input.js). H.2 надстраивает
  тиры и сирену, а не строит с нуля.
- **Idle-авторемонт существует**: рабочий в простое сам латает
  повреждённую технику в радиусе обзора (`findRepairTarget`, только
  `vehicle`, здания — «решение игрока»). H.1 расширяет: здания +
  диспетчеризация, а не «рядом».
- **Ремонт стоит минералов**: `REPAIR_HP_PER_MINERAL = 6` (config.js),
  здание 26 HP/с ≈ 4.3 мин/с, техника 18 HP/с = 3 мин/с; без минералов —
  пауза + тост раз в 6 с; по готовности — `resumeGather` (возврат
  к добыче уже встроен).
- **Лаба**: 4 слота QWER + X отмена; панель держит 5+ кнопок
  (прецедент: 4 ресерча + отмена). 5-й слот влезает без вёрстки.
- **Завод**: 3 продукта QWE + грейд R. 4-й продукт упирается в R —
  ему нужен свой ключ.
- **КЦ**: Q (техник) + R (грейд, появится сам). В контексте здания
  свободны T/G (в buildMenu T/Y/U/I заняты — контекст другой,
  конфликтов нет; глобальные A/P/V/H/Tab/Space/`,`/`.` не пересекаются).
- **ИИ новое не подхватит**: исследования — фиксированный список
  из 4 ключей (ai.js), производство — явные типы (пехота/техника
  по профилю, волны — спавн по типам), `startGrade` вызывается только
  из хуков игрока. Разведчик/авторемонт/грейды КЦ для ИИ невидимы
  без единого `if` — плюс затворы ниже (§2).
- **Туман**: `visible`/`explored` (fog.js), `tileExplored`;
  кристаллы и на карте, и на миникарте рисуются только на разведанном.
  Разведчик, открывая туман, открывает и жилы автоматически —
  «подсветка» = тост+пинг о впервые увиденном.
- **Зеркала**: один `type` id, `hname/aname`, `hdesc/adesc`, иконки
  `a_*`, отрисовка по `u.faction` (drawUnit). Новый юнит зеркалится
  данными + двумя ветками спрайта.
- **UNLOCK_AT** — по индексу массива MISSIONS (бонусные главы продолжают
  шкалу), скирмиш — всё открыто; Кодекс «Арсенал» — `unlockAfter =
  UNLOCK_AT` типа, строки — из LORE.md §6.
- **Приказы**: `u.order.kind` — idle/move/attack/gather/build/repair/
  garrison/heal… «Без приказа» для H.4 = `kind === 'idle'`, точка.

## 2. Предложение

### H.0. КЦ Г2/Г3 — грейды-ключи (без статов!)

Ответ на F2 §3 («грейд штаба меняет осадную математику»): грейды КЦ
не меняют НИ ОДНОГО числа — ни hp, ни обзор, ни темп. Это ключи,
открывающие способности (§H.1–H.4). Осадная математика обеих сторон
побайтово та же; `checkEnd` считает тип/смерть — семантика «снеси штаб»
нетронута. Враг не грейдится (ИИ `startGrade` не вызывает — §1).

`GRADES.cc = [null, null, { cost: 240, time: 30 }, { cost: 400, time: 45 }]`
— формула F.2 (60%/30 с → 100%/45 с) от базы КЦ 400. Кнопка KeyR
и шевроны — бесплатно от каркаса F.2. Текст грейда — не статы,
а разблокировка (см. §3). Грейд пер-здание (второй КЦ качается сам,
прецедент F.2); проверки «есть ли Г2/Г3» — по любому живому своему КЦ.

### H.1. Авторемонт (КЦ Г2 → ресерч в лабе)

`UPGRADES.autoRepair = { max: 1, costs: [150], times: [60],
requiresGrade: { type: 'cc', level: 2 } }`. Одноуровневый — вкл/выкл.

- **Слот**: 5-я кнопка лабы, KeyT. До Г2 — видна замком с типом
  «Требуется КЦ грейда II» (открываемость механики); `startResearch`
  возвращает новый код `'grade'`.
- **Эффект** (`st.tech.player.autoRepair`, тик 0.5 с): цели — свои
  достроенные здания hp<maxHp + своя техника hp<maxHp в радиусе
  15 тайлов (480px) от любого живого своего КЦ. Ремонтники —
  ближайшие: сначала idle, потом gather; кап 2 на цель живым учётом
  (`repairersOf`, приём G.4); приказы attack/move/build/garrison
  святы — не дёргаем. По готовности — `resumeGather` (встроен).
- **Экономика**: чинит за минералы по общему тарифу (пауза при нуле —
  встроена). Пол-КЦ (750 HP) ≈ 125 минералов — заметно, не разорительно.
  Отвлечённые возвращаются в раздачу F.1 (2-на-кристалл) — поля не
  оголяются: кап 2/цель × редкие цели.
- **ИИ**: двойной затвор — фиксированный список исследований (не знает
  ключа) + `requiresGrade` (КЦ не грейдит). `st.tech.enemy.autoRepair`
  навсегда 0.
- **Кампания**: лаба с миссии №11 — ресерч доступен в №11–14, бонусах
  и скирмише; сами грейды КЦ — с любой миссии с базой (КЦ открыт всегда).
  В noBase-миссиях (№8/13/17) механики тихо отсутствуют — это норма.

### H.2. Тревога (КЦ Г2)

Триггер и кулдаун 8 с — существующие. Новое — **тиры**:

- **Базовый тир**: урон своему в радиусе 15 тайлов от живого КЦ игрока
  + есть КЦ Г2+ → сирена `sound.alarm()` (новый рецепт в audio.js:
  двухтональная, sawtooth 660/520 ×2 — собирается из `tone()`,
  без ассетов) + красный тост + пинг. Без Г2 — мягкий пинг как сейчас.
- **Полевой тир**: урон вне радиуса — как сейчас (пинг+тост), всегда.
- Строка тоста — существующая `underAttack` (звук различает тиры,
  новых строк не плодим — привет пакету I). `lastAlertPos`/H — без
  изменений.
- **Техники при тревоге — ОСТАЮТСЯ на местах.** Решение ресерча:
  автопрятки оголяют экономику при каждом харассе сильнее, чем гибель
  пары техников; бункер — 4 места под пехоту, RMB-фильтр рабочих
  не пускает (game.js); прецедент SC2 — рабочие не разбегаются.
  Ручной ответ — за 2 клавиши: H (к тревоге) + Comma (армия) / H.4.
  «Без лишней суеты» — буквально.

### H.3. Разведчик + «Разведать» (КЦ Г3)

**Юнит** (завод, 4-й слот, KeyT):

| Поле | Значение | Обоснование |
|---|---|---|
| hname / aname | «Следопыт» / «Слухач» | голос фракций (§6 LORE-стиль) |
| cost / trainTime / supply | 60 / 12 с / 1 | дешевле скифа (100), уровень рейнджера |
| hp / speed / sightTiles | 50 / 185 / 11 | самый быстрый (скиф 158) и глазастый (мортира 10) |
| dmg / range / projectile | 0 / 0 / 'none' | безоружен по ТЗ |
| vehicle | true | заводская машина: чинится техниками, не лечится |

- **UNLOCK_AT.scout = 2** — приходит с заводом; его появление и есть
  анонс (интро кампаний не трогаем, честность П8 — завод уже новинка
  №2). Кодекс «Арсенал» +2 записи (Гелиос/Кхарид, unlockAfter 2),
  LORE.md §6 +1 строка каждой фракции.
- hdesc: «Лёгкий ховер с дроном-наводчиком: видит на 11 тайлов, уходит
  от любой погони. Безоружен — не ставьте в строй».
  adesc: «Юркий зверёк со спорой-спутницей: чует врага и грани
  за 11 переходов. Жалить не умеет — не гоните в бой».
- **Безоружность — пять затворов** (ресерч нашёл все точки):
  1. `atkBonus` — гвард `dmg <= 0 → 0` (иначе vehAtk вооружит его +5/ур!);
  2. idle auto-acquire — `&& !u.cfg.scout`;
  3. `selectArmy`/`cycleCombat` — исключить (запятая не должна гнать его на убой);
  4. RMB-атака — фильтр (разведчик игнорирует приказ атаковать, стоит);
  5. attack-move/A-key — уже фильтруют `dmg > 0` ✓ (поверено).
  Враги его видят и бьют как обычно (`acquireTarget` симметричен) —
  так и надо: он должен уворачиваться.
- **Спрайт** (бриф для H-кода): Гелиос — лёгкий ховер + парящая
  дрон-точка с лучом; кхарид — юркий зверёк + спора-спутник.
  Токены DS, без новых ассетов. Иконки: `scout`, `a_scout`.

**«Разведать»** (кнопка КЦ Г3, KeyT — контекст свой, с заводом не спорит):
все свои разведчики с приказом ≠ `'scout'` → приказ `'scout'`.

- **updateScout** (тик 0.4 с, рандом только через `srand(st)`):
  угрозы в sight → отход от ближайшей на 6 тайлов (фолбэк —
  любая проходимая соседняя); иначе — ближайший из K=12 случайных
  неразведанных тайлов (разброс по разведчикам — сдвиг выборки
  по индексу); дошёл/точка разведана → следующий; неразведанного
  нет → idle + тост `reconDone`.
- **Подсветка**: впервые увиденное поле кристаллов в sight → тост+пинг
  (множество `st.reportedFields` по `fieldId` из map.js/F.1, fallback
  на `${tx},${ty}` для старых/тестовых карт; истощённые поля не забываем);
  видимый враг → пинг + тост `contact`, кулдаун 10 с
  (`st.lastContactT`, отдельно от боевого).
- Новые STR-строки: `contact` («Контакт с противником!» / «Чужаки
  рядом!»), `reconDone` («Карта разведана полностью» / «Рой обнюхал
  все земли»).

### H.4. «Сбор» (КЦ Г3, KeyG)

Все свои юниты с `order.kind === 'idle'` и без гарнизона → движение
к `rally` КЦ через кольцо разброса G.1 (`rallySeq` — переиспользуем).
`rally === null` → error-тост `noRally` («Сначала поставьте точку сбора» /
«Сначала укажите точку сбора») + `sound.error()`, без движения.
Собирающие/строящиеся/воюющие/разведывающие (`gather/build/attack/
repair/heal/move/scout`) — не трогаем: у них приказ. Idle-техники
идут тоже — «армия снова в кулаке».

## 4. Совместимость

- **keyTarget**: грейды не меняют тип/сторону/смерть; враг всегда Г1
  (ИИ не грейдит). Семь кей-миссий на `'cc'` + №17 на `'depot'` —
  логика победы не задета. Поражение (`bcount.player <= 0`) — тоже
  считает здания, не HP.
- **Сиды**: mapgen не тронут; новый рандом (сэмплы разведки, тики) —
  только через `srand(st)`, `Math.random` запрещён в логике (эффекты —
  как были, они вне симуляции).
- **Кампании**: тексты/условия/сиды/интро — ноль изменений. Новое
  появляется через открытые механики (завод №2, лаба №11, грейды —
  везде, где есть КЦ).
- **F.1**: раздача 2-на-кристалл в силе; авторемонт возвращает через
  `resumeGather`; ручной ПКМ-ремонт и G.4 — без изменений.
- **ИИ**: не исследует (фикс-список + затвор грейда), не грейдит КЦ,
  не строит разведчиков (явные типы), но чинит и воюет как раньше;
  вражеских следопытов не существует.
- **Зеркала**: имена/описания/иконки/спрайт — обе фракции; статы общие
  (прецедент всех 7 юнитов).
- **Края**: noBase-миссии — механик нет (зданий нет); evac-миссии —
  разведчик считается как рабочий (уже так для всех типов);
  `guardType` — не задет; второй КЦ — грейдится отдельно, проверки —
  по любому живому.
- **Сейвы/прогресс**: формат не меняется; победа/прогресс — как были.
- **Бейдж**: док поставку версии не поднимает (прецедент W: док —
  без бейджа). «Версия H · <дата>» — с H-кодом.

## 5. Отвергнутые альтернативы

- **Техники прячутся в бункер**: 4 места, RMB-фильтр их не пускает,
  автопрятки оголяют экономику; SC2 так не делает. Отклонено (§H.2).
- **Статы у грейдов КЦ** (hpMul/обзор): ровно то, против чего F2 §3;
  ключи-способности дают глубину без математики. Отклонено.
- **Сирена всем и сразу**: обесценивает Г2; тиры делают грейд желанным.
- **Вооружённый разведчик**: это скиф (уже есть). Безоружность +
  скорость 185 — отдельная ниша.
- **UNLOCK_AT позже №2**: заводу не нужен второй анонс; поздний
  разведчик пропустил бы полкампании. №2 — его дом.
- **Тумблер отключения авторемонта**: не просили; тормоз — цена
  минералами + пауза при нуле. Кандидат в пост-H, если игрок попросит.

## 7. Самоаудит дока (по процессу)

Поверял каждое утверждение по коду; нашёл и учёл до отправки:

1. **vehAtk вооружил бы разведчика** (`atkBonus` безусловно аддитивен) —
   в док заложен гвард `dmg <= 0 → 0`. Без него «безоружный» ложен
   с первым же ресерчем.
2. **RMB-атака без фильтра dmg** (game.js) — разведчик получил бы приказ
   с range 0 и залип в погоне; заложен фильтр + игнор.
3. **Завод: 4-й продукт vs грейд на R** — разведён ключами (продукт T,
   грейд R); T/G проверены на свободу в контексте здания.
4. **Ремонт платный** (6 HP/мин) — авторемонт без тормозов доил бы казну;
   тормоза: порог-кап, пауза при нуле (встроена), возврат к добыче.
5. **keyTarget-миссий на КЦ — семь**, не «пара» — грейды-ключи без статов
