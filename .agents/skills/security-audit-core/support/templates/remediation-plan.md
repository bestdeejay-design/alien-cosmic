## Правила

- P0 — немедленно, блокирует релиз. P1 — до релиза/ближайший спринт. P2 — ближайший цикл. P3 — hardening.
- После исправлений клиент указывает версии/коммиты и запрашивает retest.
- Retest — по [retest-certificate.md](retest-certificate.md). Без retest статус не меняется на «исправлено».
- Если исправление невозможно в срок — фиксируй риск-принятие с владельцем (письменно), а не молча.
