# Вики «Звёздного рубежа» — справочник командира (версия G)

Всё, что есть в Сезоне 1: юниты, здания, улучшения, механики, кампания,
управление и мир. Числа — из кода (`js/config.js`, `js/missions.js`),
сверены построчно; выдумок нет. Найденные расхождения текстов с кодом —
в [CONSISTENCY.md](CONSISTENCY.md).

![Главное меню с сезонами](img/todo-main-menu.md)

## Как читать: два облика

У каждой роли в игре — одна характеристика и два облика. Люди
«Гелиос-Индастриз» говорят уставом и инженерией, кхарид — песней
выводка. В вики первым стоит облик Гелиоса, вторым — роя:

**Дрон-техник / Собиратель** — человек слева, кхарид справа.

Имена собственные пишутся по канону [LORE.md](../../LORE.md):
эрг — строчными, «Нова», «Гадюка», «Глушитель» — в ёлочках,
Сыны Песка — без кавычек.
