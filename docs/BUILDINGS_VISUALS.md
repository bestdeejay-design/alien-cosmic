# Новые визуалы строений Alien Cosmic — концепция v4 (2.5D, Canvas2D)

> **Отказ от v2 «подиумы» (владелец: «читалась электросхемами») → v3 2.5D-архитектура: тень → фасад → приподнятая крыша, корпус на ~90% футпринта. Текущий v3 PASS (DESIGN_SYSTEM.md §6), здесь — уточнения для сетевой игры и Сезона-2 (ретранслятор, склады). Контракт: `drawBuilding(ctx,b,rx,ry)` — центр (0,0) после `translate/rotate`, габарит ~(w*h*TILE), `shadowBlur ≤9`. Без внешних ассетов.**

---

## 0. Общие слои 2.5D (все 8+1 зданий)

```
[тень]       — овал под зданием, +7/+10 px, #000 alpha .22, blur 9
[фасад]      — боковые грани (тёмные, #1a2228 / #2a1520), высота 6–10px, свет сверху-слева
[корпус]     — основной объём ~90% футпринта, скругление 6px, светлый верх, тёмный низ
[крыша]      — приподнята на 4–6px, светлее корпуса на 8%, кромка 1px #c5fff1 alpha .18
[детали]     — окна/двери/вентиляторы/зебра/шипы/слизь — плоские заливки, без blur
[состояние]  — дым/споры (HP<50%), трещины, наведение, откат, гарнизон-огонь, грейд-шевроны
[ядро/маяк]  — одно свечение (blur ≤9) + ореол alpha
```

**Цвета семейств:**

- **Гелиос:** корпус `#d0d6db`/`#a7aeb6`, фасад `#3b4047`/`#596069`, окна `#7df3e2`/`#f3c579`, зебра `#e8913a/#2b2e33`, дым `#565c64`, огонь `#ff9b2e`.
- **Кхарид:** плоть `#7a3a52`/`#ab6072`, тень `#3d1c26`, кость `#e8d9c6`, слизь `#a8ff9e`, споры `#5a4a7a`, сердце `#c43a54` (пульс).

## 1. 8 базовых + 1 сезонное здание

### 1.1 Командный центр / Гнездо-улей (4×3, 1500 HP, +10 нас)

**Гелиос-КЦ — «Штаб Рубежа»:**
- Низ — бункер 3×2 секции, усиленный угол (толстая кромка `#596069`).
- Крыша — светлая плита с 2 окнами `#7df3e2` (мигают), антенна 12px + маяк `#f3c579` (пульс 3.4 рад/с).
- Ворота — янтарь-зебра внизу (+X), при спавне — вспышка.
- **Грейды-ключи (H.0):** Г2 (240₥/30с) — антенна выше + «Авторемонт» LED; Г3 (400₥/45с) — купол радара + кнопки T/G. HP не растёт (грейд-ключ).
- **Сеть (Сезон-2):** при `networkLinked=false` — красный LED + «НЕТ СВЯЗИ» над крышей (пульс).

**Кхарид-улей — «Сердце-выводка»:**
- Купол-мясо 3 сегмента, складки `#3d1c26`, поры с слизью `#a8ff9e` (капает t*0.7).
- Сердце — центр `#c43a54` (пульс 2.2 рад/с, blur 8).
- Вход — пасть `#160a0e` с 2 клыками `#d9cfc0`.
- **Сеть:** при разрыве — сердце тускнеет, слизь сереет.

### 1.2 Дом / Нарост-кладовая (2×2, 500 HP, +8 нас)

**Дом:** модульный быт-блок, 2 этажа, окна `#7df3e2` 2×2, дверь с козырьком, зебра внизу. **Кладовая:** кокон-склад 2 купола, кость-рёбра, слизь-швы. Состояние: HP<50% — трещины + дым/споры.

### 1.3 Казарма / Инкубатор (3×2, 1000 HP, очередь 5→7→9)

**Казарма:** ангар с воротами +X, крыша с 2 вентиляторами (крутятся t*1.2), LED «очередь» (ок/варн). **Инкубатор:** родильня с 3 икрами `#5a4a7a` (пульс). **Грейд:** шевроны над крышей — II сталь `#a7b0b6`, III золото `#f3c579` + окантовка.

### 1.4 Турель «Гадюка» / Жвала (1×1, 380 HP, 8×0.65с, 150 дальн)

**Гадюка — «два клыка»:** низкий подиум 24×24, башня-спарка (2 ствола 8×2, +X), поворот к цели (по `angle`), откат при `cd`. **Жвала:** пасть на ножке, 2 клыка `#d9cfc0`, плевок — точка `#a8ff9e`. **Грейд Г2:** урон 10/дальн 165, Г3: 12/180 (числа из `GRADES.turret`). Состояние: наведение — тонкий луч-прицел (не урон).

### 1.5 Стена / Хитиновая стена (1×1, 900 HP, 30₥)

**Стена:** бетон-блок `#596069` с зеброй верх, скос 45° свет. **Хитин:** хитин-пластина `#4a2e44` с шипом `#d9cfc0`. Тянется линией: превью цены (уже в `input.js` line-drag). Высокий HP/цена — читается «толстым».

### 1.6 Бункер / Кокон (2×2, 1100 HP, гарнизон 4→6→8)

**Бункер:** ДОТ с бойницами 4 (→8), гарнизон — 4 пехотинца внутри неуязвимы, стреляют сами (дальн 140). Крыша — плоская с мешками. **Кокон:** мясистый ДОТ с щелями, бойцы жалят через щели. **Грейд:** Г2 — гарнизон 6/HP×1.25, Г3 — 8/×1.5 (см. `GRADES.bunker`). Гибель — выброс наружу.

### 1.7 Завод техники / Яма выводка (3×3, 1300 HP, очередь 5→7→9)

**Завод:** цех с краном, ворота +X, крыша с трубой (дым при производстве). Производит: Скиф/Скользень, Бастион/Громила, Нова/Спогром, Следопыт/Слухач (с М3). **Яма:** выводковый котлован, щупальца `#ab6072`, слизь. **Грейд:** темп ×1.25/×1.5.

### 1.8 Лаборатория / Узел эволюции (3×3, 900 HP, 4 ветки ×3)

**Лаборатория:** наука-блок, купол-линза `#7df3e2`, антенны. Исследует: оружие/броня пехоты (+3/−2), орудия/плиты техники (+5/−3), Авторемонт (после КЦ Г2). **Узел:** эволюц-купол, споры внутри (крутятся). **Состояние:** LED «исследование» (work-циан) + таймер.

### 1.9 Сезонное: Ретранслятор / Склад (Сезон-2, новые)

**Ретранслятор (Сезон-2 М6):** мачта 1×1, антенна-ромб `#76e3d7` (пульс), состояния `off/on/destroyed`; включает только герой (удержание). При `on` — ореол связи (кольцо 480px `ALARM_BASE_RADIUS` в симе, на карте — пунктир). **Склад (М9):** контейнер 2×1, запас `supply` лимит; при перерезании — янтарь-«голод» иконка.

## 2. Состояния — видно без панели

| Состояние | В мире | В панели (LED) |
|---|---|---|
| Строится (15%→100%) | штриховка + сварка-искры | warn blink + % |
| Под огнём (HP<50%) | дым `#565c64` / споры `#5a4a7a` + трещины (ветка) | err blink «Под огнём!» |
| Производит | вентилятор крутится, труба дымит | ok «Производство» + ETA |
| Гарнизон n/m | бойницы светятся, стволы торчат | ok/work «Гарнизон n/m» |
| Грейд (30/45с) | шевроны II/III над крышей, здание работает | work «Грейд…» + таймер |
| Нет связи (С2) | антенна тёмная, красный крест | err «НЕТ СВЯЗИ» |
| Исследование | линза пульсирует | work «Исследование» |

**Дым/споры:** `buildings.js:drawBuilding` — клуб t*1.2, подъём + рассеивание, один на здание.

## 3. Проверка и перфоманс

- **Стенд:** `render/gallery.mjs` — каждое здание в 3 размерах (0.75×/1×/2×) + 2 состояния (целый/горит) → PNG.
- **Blur-бюджет:** 8 зданий ×1 blur = ≤8 blur на кадр, ≤1 мс.
- **Гейты:** `check.mjs` + `audit_move.mjs` A9/A10 — считают blur, не пропускают >9.
