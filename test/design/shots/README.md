# design/shots — эталонные снимки (визуальный референс)

Рендер актуального `main`, перегенерируется скриптами `scripts/shots/`
(WebP, lossless — без потери качества; исходники PNG тяжелее в ~1.6 раза).

## Юниты

| Файл | Что на нём |
|---|---|
| `units-game-scale-1x.webp` | Ростер 7×2 в игровом масштабе (как видно в бою) |
| `units-detail-4x.webp` | То же с зумом — чтение силуэтов и контуров |
| `units-sheet-5-states-2x.webp` | Детальный лист: 7 типов × 2 фракции × 5 состояний (покой / на ходу / выстрел / груз-жар / ранен с HP-баром) |

## Здания

| Файл | Что на нём |
|---|---|
| `buildings-grid-2x.webp` | Сетка 8×2 (штаб-улей, дом-нарост, казарма-инкубатор, турель-жвала, стена-чешуя, дот-кокон, завод-яма, лаборатория-узел) |
| `buildings-in-game-1/2.webp` | Отстроенная база в бою (второй кадр — наводка турели) |

## Геймплей

| Файл | Что на нём |
|---|---|
| `gameplay-menu.webp` | Стартовый экран |
| `gameplay-start-units.webp` | Быстрый старт, выделение рамкой |
| `gameplay-attackmove-dashes.webp` | Attack-move: пунктиры маршрутов и флажок цели (Движение 3.0) |
| `gameplay-6s-later.webp` | Тот же бой через 6 с |

## Сверка стиля (контракт B5)

- Гелиос = угловатые машины: тёмный корпус `#0e2028`, панель `#223c46`,
  янтарные акценты `#f3c579`, бирюзовое ядро игрока.
- Кхарид = круглая органика: тёмная плоть, био-зелень `#9ff5b8`,
  светящееся ядро стороны.
- У каждого юнита/здания ровно одно свечение (`shadowBlur` ≤ 9).
- Сторона читается за <1 с: цвет ядра + подложка + форма маяков.
