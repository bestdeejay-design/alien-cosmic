# Новые визуалы юнитов Alien Cosmic — концепция v3 (Canvas2D, процедурно)

> **Контракт рисования (строго, DESIGN_SYSTEM.md §6):** рисуешь в повёрнутой СК `translate(rx,ry) → rotate(angle)`, нос по **+X**, центр (0,0), габарит ~±(r+8) px; цвета — токенами `COLORS.*`; тень/кольцо/HP-полоска — снаружи, не рисовать; `shadowBlur ≤9`, точечно (ядра, сопла); анимация — через поля юнита `id/moving/cd/carrying/flashT`. **Без внешних ассетов.**

---

## 0. Семейства — считывается за 0.2 с без цвета

### Гелиос — «угловатая техника на подушке»
- **Форма:** шестигранники, трапеции, клинья, панели, заклёпки-пиксели, зебра янтарь/чёрный.
- **Свет:** верхний-слева, кромка `#c5fff1` сверху, тёмный низ `#0d2028`, ядро `#c5fff1` с ореолом.
- **Семантика:** подушка ховера (овальная тень под корпусом), дюзы сзади (2 точки), ствол впереди (+X).
- **Палитра:** корпус сталь `#a7b0b6`/`#596069`, фасад `#3b4047`, стекло `#7df3e2`, визор `#e8913a`, янтарь `#f3c579`.

### Кхарид — «круглая органика с сердцем»
- **Форма:** эллипсы, сегменты-кольца, хитин-складки, шипы, слизь, пасть, сердце.
- **Свет:** та же схема, но блик — влажный (эллипс сверху), тень — глубокая фиолетовая.
- **Семантика:** лапы/складки, ядро-сердце пульсирует красным `#c43a54`, слизь `#a8ff9e` каплями.
- **Палитра:** плоть `#71334a→#ab6072`, тень `#3d1c26`, слизь `#a8ff9e`/`#9ff5b8`, кость `#d9cfc0`, пасть `#160a0e`.

**Проверка:** закрой глаза на цвет — углы vs эллипсы всё равно читаются.

## 1. Общие правила слоёв и анимации

### Слои (снизу вверх)

1. **Подложка/тень** — овал под корпусом (уже есть снаружи, не дублировать).
2. **Корпус** — основная фигура (6-угольник или эллипс).
3. **Панели/сегменты** — внутренние линии, заклёпки, складки.
4. **Оружие/лапы/дюзa** — выступающие элементы по оси +X / ±Y.
5. **Ядро** — одно светящееся пятно (blur ≤9) + ореол alpha-кругом при нужде.
6. **Груз кристалла** — гранёный друза над корпусом рабочего (если `carrying>0`).
7. **Вспышка урона** — красная накладка при `flashT>0` (общая надстройка, не рисовать в слое).

### Анимация (только рендерное время, симуляцию не трогаем)

| Параметр | Формула | Что даёт |
|---|---|---|
| `t = performance.now()/1000 + id*K` | расфазировка по id | каждый юнит живёт своей жизнью |
| `pulse = Math.sin(t*2.8)` | пульс ядра 2.6–3.4 рад/с | «дышит» |
| `bob = Math.sin(t*3.2)*1.2` | покачивание при `moving` | шаг/парение |
| `recoil = Math.max(0, 1 - cd/cooldown)` | откат ствола по `cd` | выстрел виден |
| `carryWobble` | груз качается на `t*2` | живой кристалл |

Все циклы — дешёво (sin/cos), без аллокаций, без `random()` в кадр (расфазировка — из id).

## 2. 8 юнитов × 2 облика — варианты

### 2.1 Дрон-техник (r=10) / Собиратель (кхарид)

**Гелиос — «Краб-хекс»:**
- Низ — шестигранник 22×14 px, 2 передние клешни-манипуляторa (трапеции с янтарным инструментом).
- Сверху — полу-прозрачная панель `#3b4047` с 2 заклёпками, центр-ядро `#c5fff1` (пульс).
- Сзади — 2 дюзы (2px точки `#76e3d7`), при `moving` мерцают (sin).
- Лапы-подушка — 2 боковых «крылышка» ховера (овалы `#596069`).
- **Груз:** гранёный кристалл 3-осколка `#7ed9e7` над центром, с искрой `#fff` (как `drawCrystal`).
- **Варианты:** (A) компактный краб, (B) вытянутый с 4 лапами, (C) круглый дрон-купол.

**Кхарид — «Кольчатый грузчик»:**
- Тело — 3 сегмента-эллипса (36×18, 28×16, 22×14), швы `#3d1c26`, складки.
- Голова — костяной козырёк `#d9cfc0`, усики 2× `#a8ff9e` (покачиваются).
- Ядро-фонарь — брюшко светится `#9ff5b8` (blur 6), при `carrying` — ярче.
- Лапы — 6 тонких `#ab6072` (при `moving` — перебор 3+3).
- **Варианты:** (A) 3 сегмента, (B) 2 сегмента + хвост, (C) бронированный с хитин-щитом.

### 2.2 Рейнджер (r=10) / Кристожал

**Гелиос — «Зари-9 штурмовик»:**
- Корпус — шестигранник 20×16, скос носа 45°, борта — 2 панели `#3b4047` с заклёпками.
- Ствол — прямоугольник 14×3 на +X, при `cd` откатывается на 3px, вспышка у дула при выстреле.
- Визор — горизонтальная щель `#c5fff1` (пульс 3.4 рад/с), при ранении — янтарный.
- Подушка — сзади 2 стабилизатора (трапеции `#596069`).
- **Анимация:** при `moving` — лёгкий крен ±2°.

**Кхарид — «Гребень-стрелок»:**
- Тело — овальный ползун 24×16, спинной гребень — 3 шипа `#d9cfc0` (средний выше).
- Пасть — щель `#160a0e` с 2 клыками, при стрельбе — плевок-точка `#a8ff9e`.
- Ядро — лобная точка `#c43a54` (пульс).
- Лапы — 2 боковых складки, при `moving` — волна по сегментам.

### 2.3 Скиф (r=11) / Скользень — самый быстрый (158)

**Гелиос — «Стрела»:**
- Клиновидный ховер 28×12, нос заострён, борта — 2 спарки `#596069` (стволы 10×2).
- Дюзa — сзади трапеция `#e8913a` с двумя огнями `#ffd0b5` (при `moving` — хвост 8px, blur 7).
- Панель — центральный «кокпит» `#7df3e2` (отражает свет).
- **Варианты:** (A) стрела, (B) двойной корпус-катамаран, (C) дисковый.

**Кхарид — «Спринтер»:**
- Тело — низкий хищник 26×12, 4 лапы (передние длиннее), голова с ушами-локаторами.
- Спина — 2 ряда шипов, хвост короткий.
- Глаза — 2 точки `#9ff5b8` (при `moving` — след).
- **Анимация:** бег — лапы 2-фазы, тело качается по синусу 4 рад/с.

### 2.4 Бастион (r=14) / Громила — тяжёлый (260 HP, 36 dmg, сплэш 46)

**Гелиос — «Утюг»:**
- Широкий корпус 32×20, плоский, спереди скос 30°, сзади — 2 выхлопа.
- Вооружение — спарка стволов 16×4 (бок-о-бок), при выстреле — отдача 4px + дым-клуб `addEffect`.
- Башня — низкий шестигранник `#3b4047` с ядром `#c5fff1` (пульс).
- **Сплэш читается:** широкая платформа = «бьёт по площади».

**Кхарид — «Рогач»:**
- Корпус — массивный овал 34×22, перед — 2 кристаллических рога `#d9cfc0` (14px), между ними — пасть-орудие `#160a0e`.
- Сердце — центр `#c43a54` (медленный пульс 2.2 рад/с).
- Спина — наросты-плиты `#71334a`.
- **Анимация:** при стрельбе — рога раздвигаются на 2px.

### 2.5 Нанит (r=9) / Цветень — лечит 7/с

**Гелиос — «Диск»:**
- Корпус — круг 18px, прозрачный `#a7b0b6` с крестом `+` (2px `#7dff9b`), ореол `#7dff9b` alpha 0.18.
- Кольцо — тонкий обод `#c5fff1` (пульс).
- **Лечение:** при `busyDefence` — зелёные `+` уже в `drawEffects` (не в спрайте), спрайт — лёгкий подъём на 1px при лечении.

**Кхарид — «Капля-росток»:**
- Тело — капля 18×16, цвет `#71334a`, сверху — росток `#a8ff9e` (3 листика), пульс ростка.
- Пыльца — 3 точки `#9ff5b8` вокруг (крутятся t*1.2).

### 2.6 Плазмер (r=10) / Кислотник — сплэш вблизи (74 дальн)

**Гелиос — «Казан»:**
- Приземистый корпус 22×16, сопло — воронка 10px `#e8913a→#ff806e`, при `cd` — свечение 0→1.
- Баки — 2 цилиндра по бокам `#596069` с полосками `#f3c579`.
- **Читается «вблизи»:** широкий силуэт + короткое сопло.

**Кхарид — «Пузан»:**
- Тело — бочонок 22×18, пузо `#ab6072`, складки.
- Пасть — низ, широкая, при стрельбе — сноп 36px (в `drawEffects` сплэш, спрайт — надувается на 2px).

### 2.7 Мортира «Нова» (r=13) / Спогром — осада (400 дальн, 48×3.4с)

**Гелиос — «Лафет»:**
- Платформа 30×18, гусеницы/подушка, ствол 22×3 поднимается по углу (по дальности цели — выше).
- Казённик — короб `#3b4047` с ядром-индикатором `#ffd0b5`.
- При выстреле — отдача + тряска `addShake(5,0.18)`.
- **Варианты:** (A) длинный ствол, (B) мортира-горб, (C) рельса.

**Кхарид — «Червь»:**
- Тело — сегментный червь 32×16, кольца `#3d1c26`, горб-мортира `#c43a54` с шипами.
- Голова — слепа, пасть вниз.
- При стрельбе — горб надувается, сплэш 62px уже в симе.

### 2.8 Следопыт (r=9) / Слухач — разведчик (185 скор, 11 обзор, 0 урон)

**Гелиос — «Перо»:**
- Лёгкий ховер 20×10, крылья-перо `#a7b0b6`, хвост-антенна.
- Дрон-спутник — точка `#76e3d7` на 8px над корпусом (кружит t*1.5).
- **Правило:** никогда не стреляет (затвор `atkBonus` уже в `units.js:40`), только уводит от угрозы.

**Кхарид — «Слухач»:**
- Тело — лань 20×12, уши-локаторы `#d9cfc0` (2×), хвост-спора `#a8ff9e` (кружит).
- **Анимация:** уши поворачиваются к угрозе (по `scanT`).

## 3. Микро-анимации — сводка по полям

| Поле | Что анимирует | Частота |
|---|---|---|
| `moving` | покачивание ±1–2px, лапы/дюзы, хвост | 2–4 рад/с |
| `cd` | откат ствола, свечение сопла, отдача | 1/ cooldown |
| `carrying` | груз на спине + лёгкий перекос | t*2 |
| `flashT` | вспышка урона (общая надстройка) | 0→1 за 0.22 с |
| `id` | расфазировка всех циклов | t + id*0.7 |
| `st.time` | общий пульс (не `Date.now()` в сетевой — заменить на `st.time` для детерминизма) | t |

**Перфоманс:** 200 юнитов × 1 `shadowBlur` × 1 `sin` ≈ 0.4 мс на кадр (проверено в `sim_move`).

## 4. Критерии приёмки (DESIGN_SYSTEM.md §10)

1. Сторона — за 0.2 с (бирюза/огонь + углы/эллипсы).
2. Раса — геометрией, не подписью.
3. Свет сверху-слева, тень есть у всего объёмного.
4. `shadowBlur` ≤9, один на сущность.
5. Состояние видно без панели (откат/пульс/дюзa).
6. Цвета — только из токенов (§0).
7. Без эмодзи, текст ≥9px с тенью.
8. PNG-стенд `render/gallery.mjs` зелёный.
9. `check.mjs` + `audit_move.mjs` зелёные.
10. При 0.5× зуме силуэт читается (проверяй в 16px тайл).
