## 0. Один абзац — что это

**Alien Cosmic** — браузерная RTS на границе освоенного космоса. Эрг-кристалл — энергия, за которую дерётся полсистемы. На трёх мирах Сектора Сабгир («Рубеж-64») корпорация **«Гелиос-Индастриз»** добывает грани, а аборигены **кхарид** защищают спящих сородичей: каждый кристалл — их ребёнок. Третья сила — **«Красный флаг» / Сыны Песка** — строит «Глушитель», способный погасить эрг-поля целого региона. Кампания Сезона-1 (15 миссий, 3 акта) уже играбельна; Сезон-2 (15 миссий, 3 главы) дописан как сценарий и ждёт реализации в изоляции `s2/` (см. `SCENARIO.md`). Целевая платформа — сеть: детерминизм на 30 Гц, реплеи и PvP-лобби запланированы в `ARCHITECTURE.md` §5.

**Элеватор-питч для пресса:**

> *Earth needs the crystals. The hive needs its cradles. On Frontier-64 you don’t pick a villain — you pick which children you’ll steal.*

### 1.2 Три силы — зеркальные техдеревья, разный голос

- **Гелиос** — сталь и бирюза `#76e3d7`, корпуса `#a7aeb6`/`#596069`, янтарь `#f3c579` стройки, оранжевый сплэш. Голос: устав, инженерия, «Рубеж стоит — эрг идёт». Герой Сезона-2 — капитан **Рейн** (исполнитель → свидетель → выбирающий).
- **Кхарид** — кристаллическая органика, плоть `#71334a→#ab6072`, слизь `#a8ff9e`, кость `#d9cfc0`, сердце `#c43a54`. Голос: песня выводка, «спящие грани». Героиня Сезона-2 — **Тха-Рисса** (защитница → мстительница → ищущая мир).
- **Красный флаг** — бывшие офицеры Гелиоса, красный флаг на вышках, человеческая техника + свои схемы. Цель — «Глушитель». Столица — «Кремень».

> Правило локализации (I18N.md §3.4): один смысл — два голоса. «Не хватает минералов» vs «Улью нужно больше граней».

### 2.3 Авто-режимы — фирменный комфорт (Ф1)

- **A+ЛКМ** — атака-движение строем (слоты `formationGoals`, проверка blocked, разводка спиралью).
- **Огонь на задаче** — идущий/добывающий/строящий отстреливается в радиусе оружия, не бросая дела.
- **Авто-добыча/возврат** — после стройки/ремонта рабочий идёт к сохранённой жиле (анти-толпа: штраф `TILE×2.2` за закреплённого).
- **Точка сбора на кристалле** — новые рабочие сразу добывают; ралли-каст кольцом.
- **Двойной клик** — все такие же на экране; **Tab/.** — перебор; **H** — к тревоге.
- **Анти-застревание 3.0** (AUDIT_REPORT.md): маршрут с габаритом `r×0.8`, snap старта A*, веер руления 11 проб + правило одной руки, лестница эскалации, разрыв цикла репутей, строй по карте, приоритеты (идущий держит курс).

## 3. Сезон-2 — сюжетная надстройка (сжатый сценарий → медиа)

> Полные брифы — `SCENARIO.md` (21 механика, 15 миссий, 3 главы по 5). Ниже — промо-пересказ для лендинга и соцсетей.

### Сквозное правило: СЕТЬ СВЯЗИ

КЦ управляет базой автономно, **только если связан через ретрансляторы**. Разрыв = «НЕТ СВЯЗИ» (UI), КЦ слепнет, игрок ведёт руками. Восстановление — контроль возвращается. Ретранслятор включает только герой (удержание). В главе 3 (карты 96–128) сеть — главный приз.

**Глоссарий механик Сезона-2 (для промо):**

Герой-аура → Следопыт (Дроны-разведчики) → Тропы → Ремонт → КЦ-командование → Бросок техники → Ретрансляторы/Сеть → Техника без экипажа → Ложные сигналы → Персистентность/Дилемма эвакуации → Снабжение/Альтернативная победа → КЦ на удалении → Захват нейтральных → Диверсия/саботаж → Мораль/паника → Союз → Две концовки.

### Главы (5+5+5)

**Глава 1 «ВЫСАДКА» (1–5, 64×64)** — знакомство с героями и довериями. *Хуки:* первый след Рейн, стена + турель против волн с техникой, спасение разбросанных отрядов дронами, тихий «Бросок техники» через тропы, включение КЦ и гонка экономик.

**Глава 2 «СВЯЗЬ» (6–10, 64×64)** — ретрансляторы как ядро. *Хуки:* удержание сети 1 минуту (6), ложные маяки и ремонт брошенной техники (7), оборона до эвакуации с выбором «кого первым» + персистентностью отряда дальше (8), голодание соперника через склады (9), скрытный переход с КЦ-поддержкой по радиусу связи (10).

**Глава 3 «РАСКОЛ» (11–15, 96–128)** — враг — свои. *Хуки:* разведка своей базы в разрыве сети (11), три базы + диверсия ретранслятора = слепой КЦ (12), моральный выбор «добить/пощадить» (13, флаг `mercy`), битва за узел связи с союзником, если пощадил (14), финал-«Выбор»: объединить сеть (мир) или разрушить (война) — две концовки, доступны по `mercy` + вторичным целям (15).

**Герои — не умирают:** гибель = провал миссии, не слом сезона; есть что спасать.

## 6. Новые визуалы строений и юнитов — концепция (кратко, полная — в доках)

### 6.1 Принцип семейств (DESIGN_SYSTEM.md §6–10)

- **Гелиос** — углы, шестигранники, панели, ховер-подушка, янтарь-полосы, одно светящееся ядро; слой: тень → корпус → панели → оружие → ядро (blur ≤ 9).
- **Кхарид** — эллипсы, хитин, сегменты, слизь, кость, сердце-пульс; слой: тень → мякоть → складки → шипы → слизь/сердце.
- Читаемость стороны за 0.2 с: бирюза `#76e3d7` vs огонь `#ff806e` (кольца, трассеры, миникарта) + геометрия, не подпись.
- Состояние видно: LED в панели + признак в мире (наведение/откат/дым/трещины).

### 6.2 Юниты v3 (предложения, Canvas2D, процедурно, без ассетов)

*Подробности, код-скелеты `drawUnit` и микро-анимации — `docs/UNITS_VISUALS.md`.*

- **Дрон-техник / Собиратель** — приземистый краб-хекс с клешнями-манипуляторами vs кольчатый грузчик с ядром-фонарём; `u.moving` → лёгкое покачивание, `u.carrying` → гранёный кристалл на спине.
- **Рейнджер / Кристожал** — шестигранный «Зари-9» с откидным стволом vs ползун с выдвижным шипом; откат ствола по `u.cd`.
- **Скиф / Скользень** — клиновидный ховер с форсаж-хвостами vs четвероногий спринтер; след от дюз пульсирует `performance.now + id`.
- **Бастион / Громила** — широкий «утюг» с двумя стволами vs рогатый танк; залп — отдача + `addShake`.
- **Нанит / Цветень** — прозрачный диск с крестом vs капля с ростком; лечение — взлетающие `+`/`+` уже в `drawEffects`.
- **Плазмер / Кислотник** — сопло-казан vs пузатый мешок; короткая дистанция читается «широким силуэтом».
- **Мортира «Нова» / Спогром** — длинный лафет vs червь с горбом; ствол поднимается по `range`.

### 6.3 Здания v4 (2.5D-архитектура, ~90% футпринта)

*Подробно — `docs/BUILDINGS_VISUALS.md`; проверка — `render/gallery.mjs` PNG до коммита.*

- **КЦ/улей** — главный штаб: светлый бункер с окнами/антенной vs мясистый купол с пульс-сердцем.
- **Казарма/инкубатор, Завод/яма, Лаборатория/узел** — единая крыша с шевронами Г2/Г3 (сталь/золото).
- **Турель «Гадюка» / Жвала** — спарка-клыки vs пасть с двумя клыками; поворот к цели, откат.
- **Стена/хитин, Бункер/кокон** — зебра vs складки; гарнизон — 4→8 бойцов в бойницах.
- Состояния: недострой — штриховка; HP < 50% — дым/споры; `LED` в панели дублирует.

## 7. Сетевая игра — что говорим в медиа
