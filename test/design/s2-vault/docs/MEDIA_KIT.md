## 2. Лендинг — три планеты по референсу MARS

### 2.1 Композиция референса → адаптация

**Референс (Mars Poster):** темный космос, по центру планета в тонком белом кольце, на кольце 4 ромба с подписями по кардиналам (ECCENTRICITY/MASS/SURFACE AREA/GRAVITY), внизу ось с «♂»-знаком + 2 прямоугольника APHELION/PERIHELION, справа внизу концентрические орбиты-икона.

**Наша версия — «Три мира Рубежа»:**

```
#planets
  .planet-card (×3) — каждая планета как Mars-постер, но со своими метриками:
    - Актан-4:  Ecc 0.088 · Mass 0.42 · Gravity 0.71 G · Area 0.52 — афелий 1.82 AU / перигелий 1.44 AU
    - Брок-Тхаал: Crystal 0.94 · Mass 0.89 · Brood Song 9.3 Hz · Area 0.95 — афелий 2.14 / перигелий 1.78
    - Селенит-Б:  Diam 3420 km · Mass 0.18 · Period 27.3 d · Area 0.07 — апогей 384400 km / перигей 356500 km
  .system-map — 8 концентрических орбит + 3 планеты + 2 корабля + легенда (как внизу референса)
```

**Палитра:** космос `#071218`, бирюза Гелиоса `#76e3d7`, фиолет улья `#a78bdb`, янтарь дистанции `#f3c579`, текст `#e9f8f2`/`#91adae`. Свет сверху-слева, тень +7/+10.

**SVG-анимация (CSS only, без JS — важно для Pages):**

- Контур планеты — `planetFloat` 12 с scale 1↔1.018 (разнесено по 3 картам).
- Орбитальное кольцо — `orbitSpin` 22–34 с rotate 360deg (у Брока медленнее, у Селенита реверс).
- Хало — `glowPulse` 4.2 с scale+opacity.
- Системная схема — `orbitTravel` 14–26 с по концентрическим орбитам, `dashMove` 8/11 с по пунктирам, `pulseOrbit` 3.2 с у звезды.
- Респект `prefers-reduced-motion`: всё останавливается.

**Адаптив:** 3 колонки → 2 (≤1000px) → 1 (≤560px); `object-fit: cover`, `aspect-ratio: 4/5.08`. Навигация лендинга теперь 6 пунктов (планеты + бои + кампания + вселенная + управление + ещё).

### 2.2 Тексты лендинга (из locales)

- `planetsEyebrow`: «ТРИ МИРА · СЕКТОР САБГИР»

## 5. Новые визуалы — что подготовлено в этом контуре

### 5.1 Юниты (8×2) — идея

См. `docs/UNITS_VISUALS.md`: семейства **угловатая техника vs круглая органика**, один `shadowBlur` ≤9, пульс ядра 2.6–3.4 рад/с, откат ствола по `u.cd`, покачивание при `u.moving`. Для сезонной кампании каждый юнит имеет «геройскую» версию (аура-кольцо) — без новых мешей, только оверлеем.

### 5.2 Здания (8) — идея

См. `docs/BUILDINGS_VISUALS.md`: 2.5D-архитектура (тень→фасад→крыша ~90% футпринта), люди — светлая броня + янтарь-зебра, кхарид — курган плоти + слизь, шевроны Г2/Г3, состояния: недострой-штриховка, дым при <50% HP, трещины, наведение турели, гарнизон в бойницах.

### 5.3 Проверка графики

- Стенд: `scripts/render/preview.mjs` + `render/gallery.mjs` → PNG до коммита, вслепую не рисуем.
- Гейт: `scripts/check.mjs` + `audit_move.mjs` (A9/A10 считают blur).

## 6. Сетевая игра — что говорим в медиа, не обещая лишнего

**Сейчас (правда):** чистый JS без сервера, 64×64, фиксированный шаг 30 Гц, приказы-команды как данные, `srand(st)` вместо `Math.random` в логике (задел под детерминизм). Запись партии = seed + журнал команд. Реплеи возможны.

**Путь (ARCHITECTURE.md §5):** детерминизм → реплеи → лобби (Node+WS) или P2P WebRTC → рейтинги/сезоны/редактор карт (параметры генератора уже параметрические: seed/biome/lakes/rocks/rich/base).

**Сообщение для прессы:** «Сначала — идеальная одиночка в браузере. Сеть — когда логика станет полностью детерминированной. Мы идём по шагам, а не обещаниями.»
