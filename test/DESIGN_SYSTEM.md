# Дизайн-система Alien Cosmic («Рубеж 64»)

Живой документ визуального языка игры. Любая новая графика обязана
соответствовать §2–§5; чек-лист приёмки — в §10. Полный аудит всех
компонентов (2026-10-18) — в §6–§8.

## 1. Принципы

1. **Свет на тьме.** Мир тёмный, сущности светятся: ядра, окна, жилы,
   трассеры. Игрок читает бой по огням, а не по контурам.
2. **Сторона важнее расы.** Свой/чужой считывается мгновенно:
   бирюза `#76e3d7` против огня `#ff806e` — в трассеров, кольцах,
   полосках HP, миникарте. Раса — второй слой (геометрия/органика).
3. **Стилизация, не реализм.** Плоские грани, градиенты, символы.
   Объём — светотенью (свет сверху-слева), а не текстурами.
4. **Живой статус.** Состояние видно без панели: наведение, откат,
   дым, трещины; в панели — светодиод + слово (§5).
5. **Дёшево в кадре.** Не более одного `shadowBlur` на сущность
   (≤ 9), тяжёлое — в запечённый террейн, анимации — рендерным
   временем (`performance.now` + `id`), не состоянием симуляции.

## 3. Язык света и тени

- Свет **сверху-слева**: тени вправо-вниз (+7/+10 у зданий),
  верхние/левые кромки светлые, низ/право — тёмные.
- `shadowBlur` — только ключевой свет: ядро юнита/здания, друза,
  трассер, навершие. **≤ 9, один на сущность.** Окна, маяки, жилы —
  плоскими яркими заливками (+ ореол alpha-кругом при нужде).
- Взрыв (`boom`) — слоёный: огненный шар + белое ядро (k<0.45) +
  расширяющееся кольцо + 5 угольков; фракционная палитра (§2.2):
  люди — оранжевый, кхарид — кислота + фиолетовое кольцо.

## 4. Типографика и форма

- Шрифт: `Inter, system-ui` (DOM), `bold 13px system-ui` (флоаты),
  `monospace`/`bold 9px` (служебное: проценты стройки).
- Заголовки: 800–900, трекинг. Микротекст ≥ 9px, с тенью на мире.
- Скругления: панели 8–14px, кнопки 7–8px, чипы 6px, тосты 8px.
- Эмодзи в интерфейсе **запрещены** (исключение: нет) —
  только текст и рисованные иконки 26×26.

## 5. Язык статусов (светодиоды)

LED 8px + слово. Цвета: `idle` серый, `ok` зелёный, `work` циан,
`warn` янтарь, `err` красный; `blink` (1с) — требует внимания.

| Место | Состояния |
|---|---|
| Карточка здания | Строится (warn+blink+%) · Под огнём! (err+blink) · Исследование (work) · Производство (ok / warn «ждёт») · Ожидает приказа (warn) · Гарнизон n/m (ok/work) · На позиции (ok) · Активно (work) |
| Карточка юнитов | Приказ живым текстом: Ожидает/Марш/Зачистка/Атака/Добыча/Стройка/Ремонт/В гарнизон/Лечение · **Путь закрыт!** (err+blink) |
| Топбар | Снабжение: dot warn при ≥85%, crit+пульс при заторе |
| Очередь | Таймер `Nс` цианом, `ждёт` — янтарём |
| HP в панели | Тиры: >55% теал, 28–55% янтарь, <28% красный |

## 9. Анимация

- Такты: пульс ядер 2.6–3.4 рад/с, маяки/мигание ~3.4, дым/флаг —
  секунды, LED-blink 1с, тост 2.6с, пинг 2.5с, тряска ≤0.3с.
- Всё цикличное — от `t = now + id*K` (расфазировка), без `random()`
  в отрисовке (кроме одноразового запекания террейна).
- Скорость игры анимации не меняют (только симуляция в `LOGIC_DT`).

## 10. Чек-лист приёмки новой графики

1. Сторона читается за 0.2с (бирюза/огонь) — где применимо.
2. Раса — геометрией, не подписью (углы vs эллипсы).
3. Свет сверху-слева; тень есть у всего объёмного.
4. `shadowBlur` ≤ 9 и не более одного на сущность.
5. Состояние видно: LED в панели и/или признак в мире.
6. Цвета — из §2 (новый hex — только с записью сюда).
7. Без эмодзи; текст ≥ 9px, на мире — с тенью/подложкой.
8. Проверено на стенде (`render/preview.mjs`, `render/gallery.mjs`):
   PNG до коммита, вслепую не рисуем.
9. `check.mjs` + `audit_move.mjs` (A9/A10 считают blur!) зелёные.
