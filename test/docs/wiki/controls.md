# Управление — мышь, клавиатура, камера

Сверено с `js/input.js` и `js/ui.js`. Наведите курсор на любую кнопку —
тултип покажет цену, статы и роль.

## Старт из главного меню

В «Быстром бою» выберите один из шести размеров карты и сторону, затем
нажмите кнопку с подписью выбранной конфигурации. На первом запуске
рекомендуется поле 64×64, но сторона не выбирается автоматически.
Последняя сыгранная конфигурация восстанавливается и запускается одним
нажатием. Кампания живёт в отдельной карточке: её кнопка начинает миссию
по сохранённому прогрессу, а не быстрый бой.

## Мышь

| Жест | Действие |
|---|---|
| ЛКМ | Выделить; протяжка — рамка |
| Двойной клик по юниту | Все такие же юниты на экране |
| ПКМ (своё здание выделено) | Точка сбора (на кристалле — новые рабочие сразу добывают) |
| ПКМ по врагу | Атака |
| ПКМ по кристаллу | Добыча (первый — на кликнутый, остальные раскидываются) |
| ПКМ по повреждённому своему | Ремонт (по 2 техника на цель, излишек добывает) |
| ПКМ по бункеру (пехота выделена) | Занять гарнизон |
| ПКМ по недострою | Вернуть рабочих на стройку |
| ПКМ по земле | Движение строем (слоты проверяются — «в стену» не прикажут) |
| `A + ЛКМ` | Атака-движение: идти и бить всех по дороге |
| Колесо / два пальца | Панорама карты |
| Средняя кнопка (зажать) | «Взять» карту и перетащить |
| Миникарта: ЛКМ / протяжка | Прыжок / ведение камеры |
| Миникарта: ПКМ | Приказ из любой точки карты |

Стены и турели (всё 1×1) тянутся линией: зажмите ЛКМ в режиме
стройки и ведите — превью покажет цену. Выход из стройки — ПКМ/Esc.

## Клавиатура

| Клавиша | Действие |
|---|---|
| `B` | Меню стройки, дальше тип: `Q` КЦ, `W` дом, `E` казарма, `R` турель, `T` бункер, `Y` стена, `U` завод, `I` лаба |
| `Q/W/E` | Производство в казарме/заводе; `R` — грейд здания |
| `T` | Завод: разведчик; лаборатория: Авторемонт (после КЦ Г2); КЦ Г3: «Разведать» |
| `G` | КЦ Г3: «Сбор» — idle-юниты к точке сбора |
| `Q/W/E/R/T` | Исследования в лаборатории; `T` — Авторемонт за КЦ Г2 |
| `S` | Стоп | `X` | Отмена / назад |
| `F` | Выпустить гарнизон | `A` | Атака-движение |
| `P` | Пауза (Esc — снять) | `V` | Скрыть/показать панель |
| `Пробел` | Прыжок к базе | `H` | К последней тревоге |
| `Tab` | Перебор бойцов по одному (с камерой) |
| `.` | Следующий свободный рабочий (с камерой) |
| `,` | Выделить всю армию |
| `+ / −` | Зум 0.5–2.0 с якорем под курсором |
| Стрелки / край экрана | Камера (панели UI скролл не трогают) |
| `1…9` | Выбрать отряд; `Ctrl/Shift/Alt + цифра` — назначить; двойной тап — прыжок (окно 350мс) |
| `Enter` | Поставить здание под призраком (стрелки — двигать) |

## Панель и камера

Командная панель переставляется (низ / слева / справа / верх —
кнопка «Панель» на ней самой) и прячется клавишей `V`; выбор
запоминается. Камера во всех положениях держит цель на видимой
области — под панель юнитов не заводит. Статусы зданий
(производство, исследование, гарнизон) видны прямо в мире.

Выберите своё здание — инспектор покажет его живой процесс: стройку
в процентах без выдуманного ETA, а производство, исследование и грейд
с ETA, когда остаток времени известен. В покое показывается честный
статус (включая гарнизон и огонь), без фиктивной полосы. Чип очереди
сразу показывает возврат перед отменой; `X` так же сообщает возврат
для исследования и грейда. Наведите курсор, переведите фокус или
коснитесь затемнённой команды, чтобы узнать причину и дефицит. После
победы/поражения команды гаснут, инспектор остаётся читаемым.

Краевой скролл: подведёте курсор к краю игровой области — кромка
подсвечивается бирюзой (зона съезда), камера трогается после короткой
задержки — случайный проход к панели камеру не уводит. Над панелями
и топбаром зоны гаснут: там камера не реагирует. Курсор за окном —
скролл замирает. Строй доводится до края карты любого размера
(48–96): групповые приказы больше не зажимаются на тайлы 64×64.

## Трекпад (без мыши)

ПКМ — тап двумя пальцами или `Ctrl+тап`; рамка — тап + протяжка;
панорама — скролл двумя пальцами. Группы назначайте через
`Alt+цифра` (`Ctrl+цифра` перехватывают Spaces, `Cmd+цифра` —
вкладки). Полный цикл без мыши: `.`, `B`, клавиша здания, тап,
`,` — и вы снова с армией.
